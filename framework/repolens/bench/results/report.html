At a glance

Retrieval, task set notaire-holdout: same question, top-10 files

Each task prompt is sent verbatim to three retrievers. grep runs one ripgrep per prompt keyword and ranks files by TF-IDF of the matches; hybrid is repolens's BM25 + embedding anchors without the graph walk; graph adds the typed, hub-damped Personalized PageRank. Recall counts the expected files found in the top 10; recall@20 is what one MCP search call carries (10 detailed results plus 10 one-line entries).
