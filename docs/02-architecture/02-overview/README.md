# Architecture Overview

Este directorio contiene la documentación de arquitectura del sistema Notaire.

- `sad.md` — Documento de arquitectura de software que describe la migración y la arquitectura objetivo.
- `arquitectura-migracion.drawio` — Diagrama Draw.io de migración y arquitectura final.
- `architecture-legacy.puml` — Diagrama PlantUML de la arquitectura legacy.
- `architecture-target.puml` — Diagrama PlantUML de la arquitectura objetivo.
- `migration-flow.puml` — Diagrama PlantUML de la estrategia de migración.

Para comprender la arquitectura general del proyecto, comience con `sad.md`.
