# Metrics that answer time, cost and RepoLens effect per intent and overall

## Objetivo

The factory cannot say how long an intent took, what it cost, or whether RepoLens helped: cost.jsonl is empty, cost rows carry no run, and the real usage in Junie logs, Claude Code transcripts and RepoLens logs is never joined to intents.

## What Changes

Cost rows gain run, step, cache and source; cost import attributes Junie and Claude Code usage to run steps; metrics factory reports per intent, per run and overall, with the RepoLens effect; the dashboard and GitHub Pages show it.
