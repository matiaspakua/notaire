## Objetivo

The Owner asked that Notaire always use the latest RepoLens and aisdlc and always keep their metrics and benchmarks current. The main checkout served RepoLens 0.6.2 while main had 0.7.0 and nothing warned; bench results do not say which RepoLens produced them; four snapshots are refreshed by four scripts someone has to remember.

## What Changes

Stamp bench results with `repolens_version`. Add `workspace/ci/refresh-factory-evidence.py`: one ordered refresh (free by default; `--agent`, `--history` opt-in; `--dry-run`) and `--check` for stale engines and results. Session start prints the check. Run the refresh on RepoLens 0.7.0 and the latest factory runs and commit the outputs.
