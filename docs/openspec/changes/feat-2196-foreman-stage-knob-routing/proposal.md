## Objetivo

Per-stage profile knobs (#2182) exist and validate, but Cloud Foreman still routes from prose + fleet-manifest alone. The kit needs a read-only CLI that prints/resolves a Foreman **dispatch plan** from `[[stages]]` (agents, skills, mcp, model, effort) so the Foreman must consult a single profile-derived surface before dispatch. Does **not** execute agents/MCP; does **not** claim Isolator OS.

## What Changes

- CLI `aisdlc foreman plan [--stage ID] [--json]` (alias `route`) resolves a dispatch plan from profile `[[stages]]` knobs
- JSON honesty: executes=false, sandbox=false, note that agents/MCP are not run
- Empty / omitted knobs → empty plan (gates still run); never invents stages
- Notaire existing `plan` stage knobs appear in plan output (≥1 mapped stage)
- Update `.claude/agents/cloud-foreman.md` + kit foreman template to require consulting the CLI before dispatch
- Thin plan + remaining-gaps: Foreman ops habit partially kit-backed
- Never flip `[committer] required=true`
