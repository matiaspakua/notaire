# Releases are manual: Release Please runs only on the Owner's dispatch

> Governed by [CONSTITUTION.md](../../../../CONSTITUTION.md). This proposal documents
> **only this change**; permanent documentation remains the single source of truth.

| Field | Value |
|-------|-------|
| GitHub Issue | #2477 |
| Use Case | CU76 — Quality Assurance and Testing Infrastructure |
| Branch | `ci/2477_manual_releases` |
| Gate 1 status | passed |

## Objetivo

Release Please ran on every push to main, kept a bot release PR open and cut tags whose workflows broke main three releases in a row. The Owner decided releases are a manual process he triggers.

## What Changes

Release Please keeps only `workflow_dispatch`; the runbook, the public security cadence (new `manual` trigger) and the Pages copy say so; the open bot PR #2476 is closed.

## Reglas de negocio

| Rule | Source | New / Changed / Made explicit |
|------|--------|-------------------------------|
| A release starts only when the Owner dispatches it. | Owner decision 2026-11-24 (#2477) | New |
