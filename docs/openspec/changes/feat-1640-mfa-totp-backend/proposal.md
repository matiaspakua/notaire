## Objetivo

Login is password-only (OWASP A07). Slice 1 delivers the hexagonal TOTP core — enrol, verify and recovery codes with secrets encrypted at rest — without touching the login flow, so later slices can enforce the policy on a tested base (ADR-032).

## What Changes

- Domain `domain.mfa`: RFC 6238 algorithm, enrolment aggregate, recovery codes.
- Inbound ports `EnrollTotpUseCase`, `VerifyTotpUseCase`, `UseRecoveryCodeUseCase`; outbound ports `MfaEnrollmentStorePort`, `SecretCipherPort`, `RandomBytesPort`, `ClockPort`.
- Use cases in `application.usecase.mfa`.
- Adapters: `adapter.out.persistence.mfa` (JPA + Flyway `mfa_enrollments`), `adapter.out.security` (AES-256-GCM cipher, SecureRandom, system clock).
- ADR-032.

Later slices (multi_pr): 2 login policy (required for `ROLE_ADMIN`, optional otherwise) and REST endpoints; 3 Next.js enrol/verify screens; 4 Playwright, threat model, auth guide and OWASP-TOP10 A07 update.

## Reglas de negocio

| Rule | Source | New / Changed / Made explicit |
