## Objetivo

`repolens setup` writes MCP wiring for Claude Code, Cursor, Codex and OpenCode, but not for the Junie CLI. Junie loads `.junie/mcp/mcp.json` with the same server shape as Cursor. Without this wiring, Junie sessions cannot reach the RepoLens knowledge graph.

## What Changes

- `framework/repolens/repolens/setup.py` gains a `setup_junie` writer that produces `.junie/mcp/mcp.json` with the same launcher command and args as the other harnesses. `"junie"` is added to `TARGETS`, `WRITERS`, the CLI `--only` choices, and the `_wiring` doctor probe.
- `.junie/mcp/mcp.json` is committed with the generated content.
- `workspace/tests/test_repolens_integration.py` asserts Junie starts the same server as every other harness.
- RepoLens README lists Junie alongside the other harnesses.
- RepoLens CHANGELOG records the addition.
