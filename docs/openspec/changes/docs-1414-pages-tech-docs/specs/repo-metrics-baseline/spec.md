# repo-metrics-baseline

Repository topology decisions use a reproducible metrics baseline.

## ADDED Requirements

### Requirement: Metrics script exists under workspace

A Python script under `workspace/ci/` MUST collect offline-friendly repository metrics (module
counts, workflow path-filter counts, always-loaded agent file sizes, deprecated/ size) and write
JSON and/or Markdown output.

#### Scenario: Script runs without network

- **WHEN** `python3 workspace/ci/repo-metrics.py --markdown` is executed in a clean checkout
- **THEN** it exits 0 and prints or writes a Markdown baseline that includes workflow and module counts

### Requirement: Baseline committed

A baseline Markdown file MUST exist under `docs/300-development/` produced by the script (or an
equivalent checked-in snapshot regenerated by the script).

#### Scenario: Baseline document present

- **WHEN** documentation for #1197 Phase 0 is reviewed
- **THEN** `docs/300-development/REPO-METRICS-BASELINE.md` exists and cites the generating command
