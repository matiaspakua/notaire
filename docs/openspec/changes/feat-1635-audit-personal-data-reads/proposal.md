## Objetivo

The audit aspect records writes only. A read of a `Person` (DNI, email) leaves no trace, so a privacy incident cannot be reconstructed (OWASP A09, SR-08, Ley 25.326).

## What Changes

- New marker `@AuditPersonalDataRead` on the three `Person` GET handlers (single, list, search).
- `AuditAspect` writes one audit record per annotated read: user, timestamp, module, endpoint and, for a single read, the person id. Never PII values, never the search terms.
- List and search reads write one aggregated row, not one per item.

## Reglas de negocio

| Rule | Source | New / Changed / Made explicit |
|------|--------|-------------------------------|
| A read of personal data leaves exactly one audit row without PII | #1635, SR-08, RNF-12, Ley 25.326 | New |
