## Objetivo

The process self-tests are the largest fixed cost of every PR gate: 93 s in preflight, 52 s of it in workspace/tests, where most tests spawn subprocesses and wait about a second.

## What Changes

A stdlib runner (`workspace/sdlc/run_self_tests.py`) runs each test file in its own process with the same discover semantics, in a pool sized to the CPU count; preflight.sh calls it.
