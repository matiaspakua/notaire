## Objetivo

Agents deliver product work without a constitution-level duty to feed friction back into process, gates and tools; session lessons (docs/tests ignored by TDD evidence; redundant pre-push --full) stay tribal.

## What Changes

Add P12 self-improvement principle and §10 must-dos to Notaire CONSTITUTION; digest in agent card and AGENTS.md; strengthen framework/ai-sdlc Learning loop to a principle; count docs/tests in check-tdd-evidence.sh with a regression test; document PREFLIGHT_SKIP after a proven local --full in steward skill.
