## Objetivo

ADR-029 makes every installation single tenant with a standard role template that each tenant can later customize. roles and role_modules exist and are editable but no migration seeds a row, so a new installation starts with no roles.

## What Changes

- Flyway V50 seeds three template roles (Administrator, Notary, Office Staff) with module grants, insert-if-absent per role name.
- Grants are inserted only for roles V50 itself created, so a tenant's existing role of the same name keeps its own grants.
- The seeded admin account is linked to the Administrator role when it has none.
- The template is documented in the SAD.
