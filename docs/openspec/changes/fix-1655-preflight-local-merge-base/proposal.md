## Objetivo

check-sdlc-exception.sh, check-openspec-archive-hygiene.py and check-doc-traceability.py treat any HEAD with a second parent as CI's pull-request merge checkout and diff from HEAD^1. Locally, a branch that merged origin/main to stay current has HEAD^1 = its own previous tip, so the diff holds only main's new commits and preflight reports no OpenSpec path. It forced a PREFLIGHT_SKIP push on #1645.

## What Changes

- The HEAD^1 heuristic applies only in CI (GITHUB_ACTIONS=true).
- Locally the three checks diff base...HEAD, which is the merge-base diff.
- Tests cover both modes for each check.
