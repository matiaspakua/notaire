## Objetivo

The kit is distributed by copying a directory; `__version__` is hardcoded and no wheel exists, so adopters cannot pin or upgrade it and nothing tells them their profile was written for another kit version (FACTORY-PRODUCT-ANALYSIS F7, P1). This is slice 1 of 3 in #2256: pyproject, single-sourced version, a wheel that can still `aisdlc install`, and doctor skew reporting.

## What Changes

- New `framework/ai-sdlc/pyproject.toml` (+ `setup.py` build hook, `MANIFEST.in`): stdlib-only runtime, console script `aisdlc`, version read from `aisdlc/__init__.py`.
- The wheel carries `templates/`, `profiles/`, `openapi/`, `plugins/`, `optional/` and `bin/` as package data under `aisdlc/_kit/`; `aisdlc install`/`update`/`init` resolve them from there when installed and from the source tree otherwise. Tests, docs and `verify.sh` are not shipped.
- Optional profile key `[project] kit_version`; `aisdlc init`/`install` write the running version; `aisdlc doctor` reports INFO on a minor/patch difference and WARN on a major difference. No key, no output.

## Reglas de negocio

| Rule | Source | New / Changed / Made explicit |
|------|--------|-------------------------------|
