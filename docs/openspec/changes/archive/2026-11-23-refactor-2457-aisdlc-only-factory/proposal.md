# Notaire uses only aisdlc: remove Factory Control and agentic-os, rename the dashboard and contract

## Objetivo

The Owner decided Notaire runs its AI SDLC only through the aisdlc kit and its dashboard. The external Factory Control and agentic-os projects are separate experiments, yet Notaire still cites them (profile comments, kit test docstrings, a cross-repo assessment) and aisdlc's own dashboard and contract are named "Factory Control", which makes the two products indistinguishable. First slice of epic #2456.

## What Changes

Rename the aisdlc dashboard brand to **AI SDLC Factory** and the contract file to `openapi/aisdlc-factory.openapi.yaml` (paths unchanged). Restate the rules borrowed from agentic-os and Factory Control on their own terms. Archive the cross-repo assessment. Add a guard that fails when a tracked file outside the archives names agentic-os or `factory-control`. Remove the untracked leftovers `framework/ai-sdlc/repolens/` and `.factory/`.
