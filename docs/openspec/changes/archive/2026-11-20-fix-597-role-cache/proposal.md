# Cache the role catalog list

> Governed by [CONSTITUTION.md](../../../../CONSTITUTION.md). This proposal documents
> **only this change**.

| Field | Value |
|-------|-------|

| Use Case | CU74 — Performance and Caching Strategy |
| Branch | `cursor/597-role-cache-47dc` |
| Gate 1 status | passed |

## Objetivo

Every role list read hits the database. The catalog is read on nearly every page and changes only when an administrator edits it.

## What Changes

- `findAll` on the role catalog port is cached for 60 seconds.
- Create, update, and delete drop that cache.
- Lookup by id or name stays uncached, so a duplicate name is still refused from the persistence port. The other catalogs named in #597 are unchanged. The issue stays open.
