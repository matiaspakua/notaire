## Objetivo

`aisdlc metrics lead-time` is fixture-only (#2138). Operators cannot measure real Notaire issues without hand-building JSON. Gap audit rank 2 asks for a read-only ForgePort that fetches the same event pair via `gh` — no forge write, no check attestation, no `factory/gate`.

## What Changes

- Add a read-only ForgePort (`aisdlc/forge.py`) that builds the #2138 sample document for an issue via injectable `gh` runner.
- Extend `aisdlc metrics lead-time --issue N` (keep `--fixture` for offline/TDD).
- Same event pair: `issue.created_at` → earliest linked `pull_request.checks_green_at`.
- Document Notaire validation commands + rc; update METRICS.md / FACTORY-ROADMAP note.
- Never mutate the forge from this path.
