## Objetivo

Epic #2134 closed; Owner runtime_* still unset. Need design boundary so Isolator is not confused with aisdlc committer policy dry-run or YAML sandbox flags. No fake OS sandbox; no required=true; do not invent Owner committer identity.

## What Changes

ADR-004 Isolator/sole-committer runtime boundary (grants, write set, agent never commits, YAML≠OS isolation). Cite aisdlc committer as policy dry-run Isolator must eventually enforce. Stub IsolatorPort + doctor INFO no-evaluable. FACTORY-FOUNDATION/ROADMAP pointers.
