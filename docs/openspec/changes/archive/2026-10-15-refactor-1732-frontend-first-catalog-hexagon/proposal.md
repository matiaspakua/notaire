## Objetivo

ADR-030 FE DoD requires core/ + adapters/http + composition/. Lint ratchet (#1696) exists but no domain modules yet. Mirror the backend-clean identification-types catalog so UI/hooks stop importing api-client.

## What Changes

- Add frontend/src/core/identification-type (domain + application/ports + use cases; no React/Next/api-client).
- Add adapters/http/identification-type implementing the gateway via api-client.
- Add composition wiring; hooks call use cases only.
- Move ApiError out of api-client so UI can type-check HTTP status without importing the client.
- Shrink eslint-suppressions for the identification-types hook and admin page; pin in architecture-boundaries test.
- Existing Vitest admin/people tests and Playwright TS-0139 stay green.
- Omit CHANGELOG Unreleased while Release Please #1766 holds the file.
