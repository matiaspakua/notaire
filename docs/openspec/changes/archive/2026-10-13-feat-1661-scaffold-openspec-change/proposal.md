## Objetivo

Gate 1 costs about a dozen tool calls and several validator round-trips per change, mostly template-comment cleanup and hand-edited checkboxes. Autonomous agents repeat this for every issue; `seed-openspec-change.sh` copies templates but leaves every section to hand-editing.

## What Changes

- New `workspace/sdlc/scaffold-openspec-change.py` with `scaffold <spec.json>` (writes proposal, design, delta spec, tasks group 4, traceability coverage rows; creates the folder if missing) and `complete <name> --test <TestName>` (ticks groups 1-8 and 9.1/9.3, marks the test passing).
- Guard test scaffolds a change in a temporary repo copy and runs `validate-sdlc-plan.sh` and the task-completion gate on it.
- `ai-agent-workflow` rule documents the commands.
