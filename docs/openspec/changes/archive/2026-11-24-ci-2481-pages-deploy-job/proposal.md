# Deploy Pages in its own job so the artifact exists when it is fetched

> Governed by [CONSTITUTION.md](../../../../CONSTITUTION.md). This proposal documents
> **only this change**; permanent documentation remains the single source of truth.

| Field | Value |
|-------|-------|
| GitHub Issue | #2481 |
| Use Case | CU76 — Quality Assurance and Testing Infrastructure |
| Branch | `ci/2481_pages_deploy_job` |
| Gate 1 status | passed |

## Objetivo

The Pages deploy failed on its first attempt twice in a row on main: deploy-pages could not see the artifact the same job had just uploaded; a re-run succeeded.

## What Changes

Split the workflow into a build job (uploads) and a deploy job (needs: build, github-pages environment).

## Reglas de negocio

| Rule | Source | New / Changed / Made explicit |
|------|--------|-------------------------------|
| Pages deploys from a job that starts after its artifact is registered. | #2481; GitHub's documented Pages layout | New |
