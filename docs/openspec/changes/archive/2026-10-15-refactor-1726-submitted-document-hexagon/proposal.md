## Objetivo

`SubmittedDocumentController` is still repo-only: it injects Spring Data repositories and JPA entities, carries `@Transactional`, and holds due-date inheritance rules in the web layer. Document types are already a clean hexagon (#1705). This slice moves the instance aggregate behind domain-typed ports without changing the REST contract.

## What Changes

- Characterization tests of current REST behaviour stay green.
- Domain `SubmittedDocument` plus inbound/outbound ports (domain types) and `@Service`/`@Transactional` use cases for query/manage.
- Persistence adapter over the legacy `business.SubmittedDocument` entity; keep entity for other consumers until last caller migrates.
- Controller calls inbound ports only (no repository/jpa/business imports; no controller `@Transactional`).
- Shrink ArchUnit R1 baseline for this controller; no baseline growth.
- **Omit CHANGELOG Unreleased** while release-please #1718 holds the lane.
