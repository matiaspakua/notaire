## Objetivo

The folios administration page had 65% branch coverage (30 uncovered branches). Twenty-two behaviour tests raise it to 94% and fail when the notary requirement, the deed-link exclusion, the create/edit split or the status filter is broken.

## What Changes

`folios-page-actions.test.tsx` (22): required fields, create with every value, cleared year and deed, failed save with fallback and server reason, edit with PUT, the deed already linked to another folio, list dashes, the server-side status filter, delete dismissal and failure, load-error retry, and the folio-type search, create, edit, failures and delete. The select and the deed picker are small test doubles because Radix Select inside a Dialog loops the focus scope in jsdom.
