## Objetivo

Mac verify-signals (#1740) left three notaire-postgres panels No data: extend-query double-prefix (pg_connections_total_pg_connections_total), notaire_exporter permission denied on deeds/budgets/people/users, and PromQL notaire_database_operation_duration_sum with no series.

## What Changes

- Reshape postgres_exporter.yml so scraped names are pg_connections_total / deeds_total / budgets_total / people_total / users_total (group + column total, no double prefix).
- Flyway V51 GRANT SELECT on those tables to notaire_exporter (least privilege).
- Point Database Operations Rate at an existing series (notaire_operation_total).
- Infra guard tests + CHANGELOG Unreleased.
