## Objetivo

Fleet manifest and local project.yml were separate authorities. The factory foundation marked both as planned harness adapters. A portable kit needs one port that reads those files in place without copying policy.

## What Changes

Add aisdlc harness list/show over profile [[harness.adapters]]. Wire cursor-cloud and local-foreman to existing YAML sources. Update inventory and ADR-002. Kit stays free of Notaire paths.

## Reglas de negocio

| Rule | Source | New / Changed / Made explicit |
|------|--------|-------------------------------|
| A permission listed in a harness source is not a sandbox; Cursor Cloud and local oMLX are different adapters | CU76 / ADR-002 / #2122 | New |
