## Objetivo

Generic page sweeps are exhausted at 69.67/62.75/65.79/70.68. The testimony movements page (24% lines) and the folio admin page (51%) carry real rules that only the slow Playwright suite protects. Behaviour tests for both raised measured coverage to 71.48/64.03/67.38/72.56 and were shown to fail when the version resend or the in-use guard is removed.

## What Changes

- `testimony-movements-page.test.tsx` (6 tests): the action each status offers, the endpoint each action calls, withdraw gated on the card number, reentry payload, error toast.
- `folios-admin-page.test.tsx` (9 tests): folio type create, empty-name refusal, edit resending the loaded version (#655), delete, in-use warning; folio in-use guards, delete, validation order, edit dialog.
- Vitest floors rise from 67/60/63/68 to 69/62/65/70 with the guard test and `code-quality.md` in step.
