## Objetivo

The alert rules and prometheus.yml are validated only statically or on a full Docker stack. A native Prometheus scraping the native backend showed on 2026-10-13 that the target is up, all 13 rules are healthy and the metric families exist, but it took manual steps and is not repeatable. A metric rename or a credentials change would blind the alerts unnoticed.

## What Changes

- New `infra/tests/test_prometheus_live.py`: starts a local `prometheus` with the repo config (target and credentials pointed at the native stack) and asserts the backend target is up, every alert rule is healthy and the metric families used by alerts return series. Skips when the binary or backend is absent.
- The cloud toolchain hook installs `prometheus` from the same release tarball as `promtool`; a guard test pins it.
