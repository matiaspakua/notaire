## Objetivo

The deeds page had 58.75% branch coverage (33 uncovered branches). Fourteen behaviour tests raise it to 90% and fail when the unsigned-only signing rule, the create-only folio requirement, the required-field gate or the new-folio filter is broken.

## What Changes

- `deeds-page-actions.test.tsx` (14): required fields and the folio rule, create, failed save, edit, delete and conflict, signing after a confirmation and its refusal, the linked folio, the number lookup and the two load errors with retry. The select is a small test double because Radix Select inside a Dialog loops the focus scope in jsdom.
