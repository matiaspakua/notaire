# Cache the identification-type catalog list

> Governed by [CONSTITUTION.md](../../../../CONSTITUTION.md). This proposal documents
> **only this change**.

| Field | Value |
|-------|-------|

| Use Case | CU74 — Performance and Caching Strategy |
| Branch | `cursor/597-identification-cache-47dc` |
| Gate 1 status | passed |

## Objetivo

Every identification-type list read hits the database. The catalog is read on nearly every page and changes only when an administrator edits it.

## What Changes

- `findAll` on the identification-type query service is cached for 60 seconds.
- Create, update, and delete drop that cache.
- The other catalogs named in #597 are unchanged. The issue stays open.

## Reglas de negocio

| Rule | Source | New / Changed / Made explicit |
|------|--------|-------------------------------|
| A catalog list may be served from memory until it is edited or the TTL passes | CU74, #597 | New |
