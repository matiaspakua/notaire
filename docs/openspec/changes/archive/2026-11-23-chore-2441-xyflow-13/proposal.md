# Migrate the workflow editor to @xyflow/react 13

## Objetivo

Issue #2440 pinned @xyflow/react 12 because 13 removed applyNodeChanges; the editor must move to the v13 change API so the dependency can be upgraded.

## What Changes

The editor applies a NodeChangeset with applyTo; the API guard checks the v13 API; the Dependabot ignore for xyflow majors is removed.
