## Objetivo

Factory success needs a first-class lead time: issue opened to PR checks green. Existing aisdlc report does not expose this with a documented event pair and evidence linkage.

## What Changes

Define event pair issue.created_at to earliest linked PR checks_green_at; add aisdlc metrics lead-time/stages; extend report with stage durations; emit via TelemetryPort when bound; Notaire sample fixture; redact secrets.
