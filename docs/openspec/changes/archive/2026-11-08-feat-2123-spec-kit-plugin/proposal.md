# Spec Kit method plugin calling the extensions API

> Governed by [CONSTITUTION.md](../../../../CONSTITUTION.md). This proposal documents
> **only this change**; permanent documentation remains the single source of truth.

| Field | Value |
|-------|-------|

| Branch | `cursor/feat-2123-spec-kit-plugin-69d3` |
| Gate 1 status | passed |

## Objetivo

The planned Spec Kit stub was never loaded. Upstream documents an extensions API; the factory needs a pinned adapter that records a real call and dry-plans argv without replacing OpenSpec.

## What Changes

Add plugins/spec-kit adapter (specify-cli 1.3.2). Record specify extension search / ExtensionCatalog.search. Declare github-spec-kit out of [plugins] allow on Notaire. Pin install in .cursor/install.sh. Remove planned/spec-kit.toml.

## Reglas de negocio

| Rule | Source | New / Changed / Made explicit |
|------|--------|-------------------------------|
| Spec Kit stays out of [plugins] allow until config validate and a dry plan pass; the extensions API is not described as absent | CU76 / ADR-003 / #2123 | New |
