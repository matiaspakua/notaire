## Objetivo

When the OTel collector hostname is unresolved (ZAP CI, bare jar, partial stack), the backend spams ERROR on every OTLP export. Hibernate @Temporal deprecation WARN floods Bruno/E2E logs. Neither is actionable; both bury real faults (#1736).

## What Changes

- Default OTLP metrics and tracing export to off; docker-compose enables them when the collector is part of the stack.
- Raise `org.hibernate.orm.deprecation` to ERROR so Temporal WARN noise is silenced until entities migrate to java.time.
- Unit test guards the properties; no CHANGELOG (ops/logging only).

## Reglas de negocio
