# Build files select their own preflight groups

> Governed by [CONSTITUTION.md](../../../../CONSTITUTION.md). This proposal documents

| Field | Value |

## Objetivo

After #2493 the PR gate is fast, except when a branch touches a build file: docker-compose, Dockerfile, pom.xml and workspace/stack still forced every group, so a compose change ran 6 min including 4 min of kit self-tests it cannot affect.

## What Changes

Replace the force-all list with explicit group mappings; tests pin the table; CI-PREFLIGHT.md names it.

## Reglas de negocio

| Rule | Source | New / Changed / Made explicit |
|------|--------|-------------------------------|
| No path selects every preflight group | Issue #2497 (follow-up of #2493) | New |
