# Factory backoffice and runtime pages do not scroll sideways at 360 px

## Objetivo

Measured on main 83b551a7 with Chromium at 360 px: the backoffice Runs page has 143 px of horizontal page scroll, because main is a grid item with the default min-width auto and the report pre widens the track. The design record (#2251 section 6) requires no horizontal page scroll at 360 px.

## What Changes

- `main` gets `min-width: 0` in `backoffice_html.py` and `runtime_html.py`, so the grid item can shrink and `pre.json` scrolls inside itself.
- Regression tests assert the rule in both rendered shells.
- Evidence: scrollWidth - clientWidth 143 -> 0 on `?module=runs` when the rule is injected; the other 11 pages measured 0 and axe reported 0 violations on all 12 pages at 1280 and 360 px.
