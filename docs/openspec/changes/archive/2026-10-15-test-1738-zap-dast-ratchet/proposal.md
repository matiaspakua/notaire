# Ratchet OWASP ZAP DAST from warn-first to blocking allowlist

> **only this change**; permanent documentation remains the single source of truth.

## Objetivo

Weekly ZAP baseline is warn-first (`fail_action: false`). Latest run has High/Medium/Low = 0 and only Informational Sec-Fetch-* (90005) noise on an API target. Flip to a failing gate with an allowlist for accepted informational rules (#1738).

## What Changes

- Add `.zap/rules.tsv` allowlist (ignore plugin 90005 Sec-Fetch headers for API baseline).
- Set `fail_action: true` and wire `rules_file_name` in `dast-zap.yml`.
- Update security gate surface tests, catalog CI wording, and cybersecurity docs.
- CHANGELOG-free (CI/docs).
