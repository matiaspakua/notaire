## Objetivo

The dashboard of PR #2383 runs on fabricated run events, writes profile files without token, scope or actor, serves one project, has no tests and does not type-check; RepoLens is nested in the kit.

## What Changes

Rebuild the dashboard server as a contract client over several workspaces with per-user tokens; add multi-token serve auth and a coach module to the kit; move RepoLens to framework/repolens.

## Out of Scope

- SaaS tenancy, an identity provider or OAuth: users are named kit tokens.
- Running agents from the dashboard: only the kit's run requests; adapters move runs.
- Uploading coach data anywhere: the report stays on the machine.
