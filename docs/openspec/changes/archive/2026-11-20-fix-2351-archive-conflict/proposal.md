# Archive conflict does not carry a JPA entity

> Governed by [CONSTITUTION.md](../../../../CONSTITUTION.md). This proposal documents
> **only this change**.

| Field | Value |
|-------|-------|

| Use Case | CU85 — Archivar gestión |
| Branch | `cursor/2351-archive-conflict-47dc` |
| Gate 1 status | passed |

## Objetivo

`FoldersInWaitException` lives outside the domain and holds `business.ProcedureFolder` rows. The archive rejection already has a domain exception that carries folder numbers. The JPA type should not leave the persistence adapter.

## What Changes

- Archiving with a folder on hold throws `ManagementArchiveConflictException` with the folder numbers.
- `FoldersInWaitException` is removed.
- Report builders, audit, security, and `DataInitializer` still import `business.*`. The issue stays open.

## Reglas de negocio
