## Objetivo

In a fresh worktree the server-backed Playwright step fails on a missing node_modules, and a failed openapi:types:check leaves a file the reachability scan misreads.

## What Changes

One ensure_e2e_deps helper used before Playwright and the e2e lint; openapi:types:check always removes its temporary file.
