# Raise the Vitest coverage floors to the measured level

> Governed by [CONSTITUTION.md](../../../../CONSTITUTION.md). This proposal documents
> **only this change**; permanent documentation remains the single source of truth.

| Field | Value |
|-------|-------|

| Gate 1 status | passed |

## Objetivo

The enforced Vitest floors (76/68/72/78) lag the measured coverage after the #1246 page tests (88.81/81.07/87.61/90.12). Raising them to 86/79/85/88 keeps two points of headroom and stops the gain from eroding.

## What Changes

`frontend/vitest.config.ts` thresholds, the DOCUMENTED floors of `vitest-coverage-thresholds.test.ts` and the floor table in `.claude/rules/code-quality.md` move together. No floor is lowered.
