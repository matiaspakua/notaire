## Objetivo

The reports page had 58% branch coverage (20 uncovered branches). Nineteen behaviour tests raise it to 98% and fail when an id gate, the optional notary/folio-type filter, the success confirmation or the catalog error is broken.

## What Changes

`reports-page-actions.test.tsx` (19): the four id-based reports gated on their id, the monthly, tax and index-book reports with and without a notary and folio type, download success and failure (fallback and server reason), and the catalog loading, error and retry. The select is a small test double because Radix Select loops the focus scope in jsdom.
