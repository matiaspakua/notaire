## Objetivo

TS-0109 (mobile project) sticks on AppShellSkeleton (Cargando…) because storageState from global-setup often has HttpOnly cookies but empty localStorage notaire-auth; dashboard layout requires isAuthenticated from Zustand persist.

## What Changes

After API login in global-setup, write notaire-auth into page localStorage before saving admin-auth.json; harden TS-0109 to wait for app-shell-skeleton to clear and stub desktop people API.
