## Objetivo

`HistoryController` is the next largest mixed/repo-like ArchUnit R1 hotspot (~6 baseline edges): it injects `HistoryRepository`, `DeedManagementRepository`, and `ManagementStatusRepository` and imports `business.*` entities with `@Transactional` on the web adapter.

## What Changes

- Add ManageHistoriesUseCase + QueryHistoriesUseCase (and implementations) owning CRUD and list paths that currently hit repositories from the controller.
- Move `@Transactional` and entity/repository access out of the web adapter into HistoryOpsPort/adapter.
- Controller ports-only; shrink ArchUnit R1 for HistoryController (six baseline edges).
- Characterization/unit/integration tests stay green.
- Omit CHANGELOG Unreleased while Release Please #1766 holds it.
