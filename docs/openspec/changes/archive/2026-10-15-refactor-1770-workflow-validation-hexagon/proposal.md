## Objetivo

`WorkflowValidationController` is the last repo-only web controller (~3 R1 edges). It injects three Spring Data repositories only to feed WorkflowValidationService. Reuse workflow catalog ports from #1728–#1730 and move orchestration behind ValidateWorkflowUseCase.

## What Changes

- Add ValidateWorkflowUseCase + ValidateWorkflowService (catalog ports + domain validation).
- Refactor WorkflowValidationService to validate domain WorkflowNode/WorkflowTransition (no business entity imports).
- Controller ports-only; ArchUnit R1 clears three baseline edges.
- Update controller/service unit tests.
- Omit CHANGELOG Unreleased while Release Please #1766 holds it.
