# Refuse absolute aisdlc install paths

> Governed by [CONSTITUTION.md](../../../../CONSTITUTION.md). This proposal documents
> **only this change**; permanent documentation remains the single source of truth.

| Field | Value |

## Objetivo

Absolute --path values were strip('/')-normalized into in-repo relatives, scaffolding the wrong tree.

## What Changes

Normalize rejects absolute and ~/ paths before stripping; regression test proves no in-repo twin.

## Reglas de negocio

| Rule | Source | New / Changed / Made explicit |
|------|--------|-------------------------------|
| Kit install stays inside project root via relative paths only | lifecycle #2135 | New |
