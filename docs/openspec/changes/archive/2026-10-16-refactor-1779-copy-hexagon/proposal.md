## Objetivo

`CopyController` is a mid-size mixed ArchUnit R1 hotspot (~5 baseline edges): it injects `CopyService` plus `PersonRepository` / `TestimonyRepository` and imports `business.*` with `@Transactional` on the web adapter.

## What Changes

- Add ManageCopiesUseCase + QueryCopiesUseCase and CopyOpsPort/adapter owning CRUD and FK resolution currently in the controller.
- Move `@Transactional` and entity/repository access out of the web adapter.
- Controller ports-only; shrink ArchUnit R1 for CopyController (five baseline edges).
- Characterization/unit/integration tests stay green.
- Omit CHANGELOG Unreleased while Release Please #1766 holds it.
