## Objetivo

Notaire's AI SDLC is mature but welded to this repo. Other products cannot adopt it without rewriting. Owner asked for a reusable, evidence-derived framework kit plus a published case study.

## What Changes

- Add framework/ai-sdlc kit (profile, gate runner, templates, adoption guide) with tests.
- Add ai_sdlc_framework.md evidence report.
- Commit .claude/skills/ui-design and index it.
- Publish GitHub Pages case-study section under /ai-sdlc.
