## Objetivo

The Owner made a full Ports and Adapters architecture, in backend and frontend, the top priority (epic #1693). The repository still documents a layered backend (SAD 5.2, refactoring.md), ADR-021 limits the pattern to the payment slice, and nothing tells an agent how to do a slice or what done means.

## What Changes

- ADR-030 accepts the target architecture, dependency rules, conventions, enforcement and migration method for both tiers and supersedes ADR-021's scope limit.
- SAD sections 5.1 to 5.3 describe the target and the measured gap, in Mermaid.
- A new on-demand rule hexagonal-architecture.md holds the per-slice checklist; refactoring.md no longer contradicts it.
- The hexagonal-arch skill gets a Notaire appendix with worked backend and frontend slices and the anti-patterns found here.
- AGENTS.md lists the new rule.
