# Fast pull-request preflight; the complete preflight gates the release

> Governed by [CONSTITUTION.md](../../../../CONSTITUTION.md). This proposal documents
> **only this change**; permanent documentation remains the single source of truth.

| Field | Value |
|-------|-------|
| GitHub Issue | #2493 |
| Use Case | CU76 — Quality Assurance and Testing Infrastructure |
| Branch | `chore/2493_fast_pr_preflight` |
| Gate 1 status | passed |

## Objetivo

Owner direction: PRs must open much faster. A docs and Pages branch spent 24 min in `preflight.sh --full` (product Playwright 8 min, extraction boundaries and kit self-tests 8 min), a one-line preflight change forced every group, and a manual pass left no marker so the hook ran it again.

## What Changes

The hook runs the default mode; `PREFLIGHT_FULL=1`/`PREFLIGHT_ALL=1` opt in. `preflight.sh` records its own pass on a clean tree and the hook accepts an equal or stronger pass. Changes to the gate scripts no longer force every group. RELEASE.md makes `--all` the first release step. CONSTITUTION §5, the agent card, AGENTS.md, the workflow rule and CI-PREFLIGHT.md state the rule.
