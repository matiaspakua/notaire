# The production ingress publishes only the actuator health endpoints

> Governed by [CONSTITUTION.md](../../../../CONSTITUTION.md). This proposal documents
> **only this change**; permanent documentation remains the single source of truth.

| Field | Value |
|-------|-------|

| Use Case | CU78 — Security and Compliance |
| Branch | `fix/2487_ingress_actuator` |
| Gate 1 status | passed |

## Objetivo

The single ingress forwarded every `/actuator/` path, so threaddump, loggers (writable), mappings, scheduledtasks, metrics and prometheus were reachable from the internet behind one shared HTTP Basic credential. Nobody outside the private network needs them.

## What Changes

`nginx.conf`: exact and prefix locations for `/actuator/health`, `return 404` for the rest of `/actuator/`. An infra test pins it. STRIDE register SR-18 and the Threat Dragon model record the threat.
