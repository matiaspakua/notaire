## Objetivo

Phase 1 (#2086) inspected form source only. The people create/edit dialog is the first Operate surface that uses the shared FormField contract with checkboxes, required fields, and aria-invalid; it needs a rendered audit (desktop and 320px) and locks for labels, required indicators, errors, focus, disabled/loading/empty, and primary-action touch targets.

## What Changes

Run Impeccable audit on the rendered people form and shared controls; harden gaps against form-patterns / form-field-context / input / select; add failing-then-green unit and Playwright locks. Do not restyle GitHub Pages. Do not take #2070–#2074 or #2088.

## Reglas de negocio

| Rule | Source | New / Changed / Made explicit |
|------|--------|-------------------------------|
| People create/edit FormField controls SHALL expose visible labels, required indicators, linked error text, keyboard focus order, and honest disabled/loading/empty states; the primary save action SHALL meet WCAG 2.2 AA 24px (design system prefers 44px on the large/default button). | CU76 / RNF-07 / RNF-05 / #2087 | New |
