## Objetivo

Isolator OS probe/run and Grant expire shipped (#2198/#2199), but `enforces_committer`
remains `false` — axiom 2 is still only a policy dry-run (`aisdlc committer`). Ship
one honest CU76 slice: Isolator runtime custody that blocks agent `git commit` unless
Owner/runtime holds an explicit commit grant, with `enforces_committer=true` **only**
after a proven interception probe. Never fake sandbox; never flip
`[committer] required=true`.

## What Changes

- Isolator commit-custody hooks / wrap mode that refuse `git commit` unless
  `AISDLC_COMMIT_GRANT` (or equivalent) is held by Owner/runtime; agent never receives it
- Enforcement works **without bwrap** (git `core.hooksPath` custody); `sandbox` stays
  independent and still requires a real containment probe
- Extend `aisdlc isolator status|probe` (and `wrap` if needed) so JSON sets
  `enforces_committer=true` only after a failing agent-commit probe under Isolator
- CLI/doctor honesty; degrade to `enforces_committer=false` when hooks/probe unavailable
- Prefer extending IsolatorPort / #2198 path; optional thin forge-write stub only if
  required for custody design (default: git commit only)
- Update ADR-004 / FACTORY-ROADMAP / FACTORY-FOUNDATION / kit README honesty
- TDD kit tests; one heavy PR; never invent Owner identity
