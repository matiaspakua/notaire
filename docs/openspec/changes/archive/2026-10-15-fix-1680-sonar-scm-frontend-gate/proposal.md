## Objetivo

Local Sonar runs failed the frontend quality gate with ~70 new-code violations because the scanner container mounted only frontend/ and could not see .git, so Community treated the whole tree as new code (#1680). Backend Sonar blockers and related production bugs from the #1535 triage remain on main.

## What Changes

- Mount the monorepo in run-sonar.sh and set sonar.scm.provider=git so new-code is SCM-based.
- Force Maven -Dsonar.projectKey=notaire-backend.
- Clear #1535 production blockers (transactional self-invocation, PDF zero-weight divide, finally-return, SubmittedDocument self-assignment, printStackTrace→logger) without touching document-types hexagon packages (#1714).
- Document the SCM rule in code-quality.md. CHANGELOG held for serialize behind other PRs.
