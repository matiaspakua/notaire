## Objetivo

Grant profile schema (#2192) declares write_set but there is no dry-run that evaluates the diff against those globs. Adopters need a policy check with the same honesty as aisdlc committer — pass/fail/no-evaluable — without claiming Isolator OS or sandbox isolation. Remaining-gaps: Grant runtime lite = write-set check; Isolator OS still missing.

## What Changes

- CLI `aisdlc grant check [--base] [--json]` compares changed paths since base to profile Grant write_set globs
- Outcomes: pass | fail | no-evaluable (no grants or empty write_set)
- JSON notes policy-only (not OS isolation); doctor INFO denies sandbox claim
- Isolator stays no-evaluable / sandbox=false; reuse Notaire plan-sample Grant
- Kit tests for in-set and out-of-set paths; thin plan + remaining-gaps honesty
- Never flip committer.required; no bubblewrap/landlock

## Reglas de negocio
