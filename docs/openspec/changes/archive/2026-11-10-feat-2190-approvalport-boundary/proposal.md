## Why

Gap-audit rank 5 prefers **ApprovalPort design** over Wilson L1+ promotion. Need a written
custody boundary: token + channel authority, SSH/DSSE (or equivalent) mint/verify, agent never
self-approves — without a runtime that fakes approvals. Wilson waits: Notaire autonomy remains
`no-evaluable` (empty stages / n≪30).

## What Changes

ADR-005 ApprovalPort boundary (authority from token+channel; cryptographic custody; no agent
self-approval). Cite Isolator ADR-004 as peer design-only runtime; cite `aisdlc improve validate`
agent-self-approval refusal as policy surface ApprovalPort must eventually enforce. Stub
ApprovalPort + doctor INFO `no-evaluable`. FACTORY-FOUNDATION/ROADMAP + store plan pointers.
Explicit Wilson auto-promotion refusal (no vanity stages).
