## Objetivo

The budgets page had 56.49% branch coverage (67 uncovered branches, the largest frontend gap on main). Twenty-six behaviour tests raise it to 87.66% and fail when the template warning, the curated no-template message, the required-field gate or the status filter is broken.

## What Changes

- `budgets-page-actions.test.tsx` (26): create with and without template items, failed save, edit and legacy status, delete and conflict, the three list filters and the retry, the summary dialog and the items dialog with their failures. The person picker and the select are small test doubles because Radix Select inside a Dialog loops the focus scope in jsdom.
