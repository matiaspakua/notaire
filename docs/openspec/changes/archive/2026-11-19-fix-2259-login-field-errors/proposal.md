# Forms audit: empty login fields are field errors

> Governed by [CONSTITUTION.md](../../../../CONSTITUTION.md). This proposal documents

## Objetivo

The login password step rejected a blank username or password with one toast. Each blank field should carry the error.

## What Changes

- A blank username and a blank password each set `FormField error`.
- Typing in a field clears that field's error.
- No toast is shown for the blank check, and no login request is sent.
- A rejected login, a lockout, and a connection failure stay toasts.

## Reglas de negocio

| Rule | Source | New / Changed / Made explicit |
|------|--------|-------------------------------|
| A required-field error is a FormField error tied to its control, not a toast alone | FORMS-AUDIT-PLAN checklist (Errors) | New |
