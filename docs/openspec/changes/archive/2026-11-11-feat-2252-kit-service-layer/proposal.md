## Objetivo

The workflow and catalog functions print and return exit codes, so a second adapter (the read-only HTTP host, #2253) cannot reuse them. Design record #2251 section 3 puts a service layer between the kit core and every adapter.

## What Changes

- New `aisdlc/errors.py`: `KitError(code, detail)` (a `ProfileError` subclass, so existing handlers keep working) and the documented `CODES` table.
- `workflows.py` and `catalogs.py` add/update return dicts and raise `KitError`; they no longer print.
- `cli.py` handlers format text/JSON and map `KitError` to the existing exit codes (1 for already_exists/not_found on add/update, 2 otherwise).
- CLI text and JSON stay byte-identical, pinned by goldens recorded from main.
