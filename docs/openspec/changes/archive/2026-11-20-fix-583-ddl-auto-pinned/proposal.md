# Pin Hibernate ddl-auto to none

> Governed by [CONSTITUTION.md](../../../../CONSTITUTION.md). This proposal documents
> **only this change**.

| Field | Value |
|-------|-------|
| GitHub Issue | #583 |
| Use Case | CU76 — Quality Assurance and Testing Infrastructure |
| Branch | `cursor/583-ddl-auto-none-47dc` |
| Gate 1 status | passed |

## Objetivo

An environment variable can set Hibernate `ddl-auto` to `update` or `create` and hide a missing Flyway migration. The running application must keep `none`.

## What Changes

- `application.properties` sets `spring.jpa.hibernate.ddl-auto=none` with no environment placeholder.
- A guard test rejects the placeholder coming back.
- Spring profiles, and making the Testcontainers path the default CI schema check, stay out of this change. The issue stays open. `workspace/stack/native.sh` still passes an explicit command-line `update` for the local native helper.

## Reglas de negocio
