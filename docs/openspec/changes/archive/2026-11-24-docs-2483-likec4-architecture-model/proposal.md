## Objetivo

The architecture views live in three formats that drift on their own: PlantUML fences in the SAD (against ADR-027), Mermaid fences in the docs and hand-written charts on Pages. The SAD still draws the retired Swing client and the deleted `jpa`/`service` packages. A model built from the code, with generated views and a drift test, keeps them true and surfaces real gaps.

## What Changes

Add a LikeC4 project (`docs/200-architecture/210-architecture-model/`) with 14 views; a generator that writes Mermaid for Markdown and a JSON file for Pages; ADR-033; rewritten SAD sections and security, deployment, monitoring and testing docs; a Pages docs page plus the interactive LikeC4 site; Issues for every code finding (#2484-#2489).
