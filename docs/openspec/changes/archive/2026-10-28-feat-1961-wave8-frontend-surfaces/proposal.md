## Objetivo

Waves 1–7 left most dashboard lists without DataTable ErrorState/retry and most secondary forms without requiredFieldErrors. Wave 8 closes that gap on existing surfaces and documents REST error/retry (#293).

## What Changes

- Wire DataTable error+onRetry on remaining list pages.
- requiredFieldErrors on secondary forms (payments client-side, copies, admin catalogs, etc.).
- REST client error/retry permanent doc (#293).
- Vitest coverage ratchet for form helpers (#1246 partial).
