## Objetivo

Grant schema (#2192), write-set policy dry-run (#2194), and Isolator design stub (#2173)
exist, but Isolator OS containment and Grant expire/kill-switch are still missing.
Ship one honest CU76 slice: optional Grant expire fields that fail closed when past,
plus an IsolatorPort backend that can probe/run under real `bwrap` containment when
available and degrade honestly (`sandbox=false`) when not. Never claim Isolator shipped
from expire schema alone; never flip `[committer] required=true`.

## What Changes

- Optional Grant `expires_at` (ISO-8601 UTC) and/or `ttl_seconds` in profile schema; validate/list/show
- Expire evaluation fails closed when past; grant check / isolator run refuse expired grants
- IsolatorPort backend: `status` / `probe` / optional `run` under real containment constrained by Grant `write_set` when `bwrap` exists
- CLI `aisdlc isolator status|probe|run` with JSON honesty fields (`status`, `sandbox`, `backend`, `enforces_committer`, detail)
- When `bwrap` missing: degrade honestly — never set `sandbox=true`
- Notaire `.aisdlc` optional expire sample as comment / non-lying sample only
- Update ADR-004 / FACTORY-ROADMAP / FACTORY-FOUNDATION / kit README: Isolator OS **started** for what works; expire shipped; refuse fake sandbox
- TDD kit tests; one heavy PR; never invent Owner identity
