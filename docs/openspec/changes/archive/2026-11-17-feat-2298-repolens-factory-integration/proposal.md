## Objetivo

Agents spend most navigation steps and tokens on grep/glob/read loops. repolens (#2297) answers the same questions in one call, but nothing registered it, several agents work at once in their own worktrees and branches, and nothing measured whether agents use it well.

## What Changes

- `repolens setup` / `doctor` and a launcher: one command wires Claude Code, Codex, OpenCode, Cursor, git hooks and `.gitignore`.
- Zero-config discovery, one store per worktree, shared vector cache, background refresh, inter-process index lock.
- Usage telemetry (server and Claude Code hook) and `repolens report`, with an advisory factory gate.
- Notaire wired: harness files, AGENTS.md pointer, stage knobs and catalog, preflight module gate, cloud bootstrap, integration guard test, framework document section.
- Module folder renamed `graph-db` -> `repolens`; benchmark data moved outside the repository tree.
