## Objetivo

SubmittedDocumentController create/update/delete catch Exception and return empty 500 or 409 bodies instead of GlobalExceptionHandler's standard ErrorResponse.

## What Changes

Remove catch (Exception) from create, update, and delete; rethrow ResourceNotFoundException and BusinessValidationException by not catching them. Add unit test for unexpected create → 500 ErrorResponse.

## Reglas de negocio
