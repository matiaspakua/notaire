## Objetivo

After 0.11.0 shipped, Deploy GitHub Page, CD, CI, SDLC Process and Pages CI were red: no v0.11 train (same as 0.10.0, #2448), a stale releases.json and a RepoLens test pinned to one measurement.

## What Changes

Add the v0.11 and v0.12 trains (code, nomenclature, GitHub milestones), a guard that the next minor's train exists, a Pages CI step that regenerates data before Vitest, the 0.11.0 release history, and RepoLens labels derived from the JSON.
