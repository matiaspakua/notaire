## Objetivo

ArchUnit R2 still flags the document application slice (~19 edges): entity-speaking DocumentRepositoryPort / ExternalDocumentRepositoryPort and entity-bound helpers ExternalEntityDocumentService, UpcomingExpirationService, DocumentCostTemplateService.

## What Changes

Move entity-bound document helpers to adapter.out.persistence; delete entity-speaking DocumentRepositoryPort and ExternalDocumentRepositoryPort; add inbound ports so ManagementController / UpcomingExpirationController stay R5-clean; shrink hexagon-baseline (~19 R2 edges).
