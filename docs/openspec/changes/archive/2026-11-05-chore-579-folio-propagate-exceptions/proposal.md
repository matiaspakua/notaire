## Objetivo

FolioController catch (Exception) returns empty 500/409 bodies instead of the standard ErrorResponse from GlobalExceptionHandler.

## What Changes

Remove catch-all Exception handlers from FolioController list/create/update/delete; keep domain Folio*Exception mapping; add FolioControllerTest for unexpected create → 500 ErrorResponse.

## Reglas de negocio

| Rule | Source | New / Changed / Made explicit |
|------|--------|-------------------------------|
| Unexpected folio API failures return standard ErrorResponse via GlobalExceptionHandler | #579, CU76 | New |
