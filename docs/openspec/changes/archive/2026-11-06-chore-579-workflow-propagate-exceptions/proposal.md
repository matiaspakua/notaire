# Workflow controllers unexpected errors use GlobalExceptionHandler

## Objetivo

WorkflowDefinitionController, WorkflowNodeController, and WorkflowTransitionController catch Exception and return ErrorResponses createFailed/updateFailed, mapping unexpected RuntimeException to misleading 409 instead of GlobalExceptionHandler's 500 ErrorResponse.

## What Changes

Remove catch (Exception) from create/update on the three workflow controllers; keep domain NotFound/Invalid/InUse catches. Add WorkflowDefinitionControllerExceptionPropagationTest for unexpected create → 500 ErrorResponse.

## Reglas de negocio
