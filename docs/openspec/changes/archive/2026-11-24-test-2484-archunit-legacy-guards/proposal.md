## Objetivo

The hexagonal rule says jpa, service, repository, business and dto get no new dependents and ports never speak a web DTO, but R6 only watched jpa and service (both empty) and R2 did not forbid dto. 40 application files already import dto and nothing stops the 41st.

## What Changes

A new rule R8 (`LegacyPackageArchitectureTest`) reports every dependent of `repository`, `business` and `dto` from outside them, ports on legacy DTOs included. Its own baseline is generated once and registered as an `aisdlc` ratchet, so it can only shrink. Docs name the rules.
