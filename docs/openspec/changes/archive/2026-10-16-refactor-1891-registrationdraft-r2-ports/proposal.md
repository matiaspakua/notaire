## Objetivo

ArchUnit R2 still flags the registrationdraft application slice (~8 edges): entity-speaking RegistrationDraftRepositoryPort and entity-bound RegistrationDraftService (Deed/Procedure/Property + Spring Data repos).

## What Changes

Move RegistrationDraftService to adapter.out.persistence.registrationdraft; delete entity-speaking RegistrationDraftRepositoryPort and unused PersistenceAdapter; keep view-safe RegistrationDraftOpsPort; shrink hexagon-baseline (~8 R2 edges).
