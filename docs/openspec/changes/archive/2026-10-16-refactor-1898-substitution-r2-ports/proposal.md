## Objetivo

ArchUnit R2 still flags the substitution application slice (~4 edges): entity-speaking SubstitutionRepositoryPort (Person, Substitution) and entity-bound SubstitutionService.

## What Changes

Move SubstitutionService to adapter.out.persistence.substitution with Spring Data SubstitutionRepository locally; delete entity-speaking SubstitutionRepositoryPort and unused PersistenceAdapter; keep view-safe SubstitutionOpsPort; shrink hexagon-baseline (~4 R2 edges).
