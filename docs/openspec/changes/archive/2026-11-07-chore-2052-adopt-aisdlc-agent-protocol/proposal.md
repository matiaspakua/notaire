## Objetivo

With the kit commands in place (PR 1), Notaire's profile and policy must use them, and agents need a written protocol for the moments they are unsure: asking the Owner, deviating from the approved change, retrying corrections and declaring risk.

- `.aisdlc/aisdlc.toml`: `[protected]` (27 globs), `[size]`, `[scope]`; `merge` runs `protected` and `evidence verify`, `pre-pr` runs `scope` and `size` (advisory).

- PR template: Deviations, AI assistance, Review budget, `Risk:`; proposal template and scaffold: `### Write set`.
