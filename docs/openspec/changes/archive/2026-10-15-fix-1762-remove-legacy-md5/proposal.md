## Objetivo

Live Sonar (`notaire-backend`) reports CRITICAL `java:S4790` on `UserController`: weak hash (MD5) is still used to verify legacy passwords after the BCrypt migration (#554 closed). Inventory classification is `fix` (#1535 / #1760).

## What Changes

- Remove `legacyMd5Hash` / `MessageDigest.getInstance("MD5")` from `UserController` (hard cutoff).
- Verify login only against BCrypt stored hashes.
- Flyway V52 migrates the V2 seed `MD5("admin")` to a BCrypt cost-12 hash of the same plaintext; test `data.sql` matches.
- Invert unit coverage so legacy MD5 login is rejected; leave historical V2 SQL text for Flyway script history tests.
- CHANGELOG-free to serialize under open hex #1763.
