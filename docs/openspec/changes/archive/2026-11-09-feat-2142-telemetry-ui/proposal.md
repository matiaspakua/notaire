## Objetivo

Operators need a thin read-only view of stage metrics, lead time, and cost without a Port-style interface builder.

## What Changes

aisdlc report --html writes a static HTML monitor from evidence ledger (+ optional lead-time fixture); read-only; never renders secrets/prompts/diffs.
