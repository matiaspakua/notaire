## Objetivo

Gates run in cloud sandboxes failed for environmental reasons that were only recorded in a chat comment (#1678). The operator runbook should hold them.

## What Changes

Add a 'Constrained hosts and cloud sandboxes' subsection to the Troubleshooting section of `infra/docs/OPERATION.md`: five entries, each symptom, cause, fix.

## Reglas de negocio

| Rule | Source | New / Changed / Made explicit |
