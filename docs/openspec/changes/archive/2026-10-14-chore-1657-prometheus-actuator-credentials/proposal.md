## Objetivo

prometheus.yml hardcodes basic_auth admin/admin for the backend actuator scrape and .env.example ships admin/admin, so the committed credential is also the one the backend accepts. A plain change-me placeholder would make the backend reject the scrape and silently stop dev metrics (follow-up to #1639).

## What Changes

- Prometheus reads the actuator user and password from files mounted as Compose secrets sourced from ACTUATOR_USER / ACTUATOR_PASSWORD.
- .env.example files use change-me-... placeholders.
- A bootstrap helper replaces a missing or placeholder ACTUATOR_PASSWORD with a random value, called by the app and infra start scripts so the stack still scrapes.
- Infra tests assert there is no hardcoded credential.
