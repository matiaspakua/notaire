## Objetivo

The document re-entry page had 38% branch coverage (26 uncovered branches). Fifteen behaviour tests raise it to 95% and fail when the due-days rule, the procedure/document pairing, the empty-documents message or the in-flight lock is broken.

## What Changes

`document-reentry-page-actions.test.tsx` (15): management rows with dashes, the page and size in the address, a page past the end, the empty list, the procedures dialog (loading, empty, documents, due days only when a document expires), closing, and the re-entry with success, the server's reason, the fallback and the in-flight lock.
