## Objetivo

Creating a protocol notebook from a selected folio that has no notary showed only a toast. The folio list should carry that error.

## What Changes

- The folio field uses `FormField error` when create is pressed and no selected folio has a notary.
- `CheckboxField` reads the FormField state, so the checkbox is `aria-invalid` and described by the alert.
- Changing the selection clears the error. No toast is shown and no request is sent.
