## Objetivo

The AI Factory pages do not yet explain RepoLens or show the committed offline and factory-loop benchmarks. Readers cannot see how the local code knowledge graph fits plan/red/pre-pr, the advisory signal gate, or the self-improvement loop after #2303/#2311/#2314.

## What Changes

- Add `/ai-sdlc/repolens/` with plain-English basics, how it works, factory plug-in, and the learning loop.
- Chart every latest committed offline bench (hit@10, latency, bytes/query, agent tool calls) and the live factory-loop A/B table from committed result files at build time.
- Link the page from AI Factory navigation, reading path, and home highlights.
- Keep English technical terms where clearer; support dark mode and ES/EN.
