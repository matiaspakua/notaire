# Login-attempt entity leaves the shared business package

> Governed by [CONSTITUTION.md](../../../../CONSTITUTION.md). This proposal documents

## Objetivo

`LoginAttempt` is a lockout row used only by the login-attempt store and its repository. It should not sit in the shared `business` package that security imports.

## What Changes

- The entity moves to `adapter.out.persistence.security`. The table name stays `login_attempts`.
- The store and the repository import the new package.
- Role, user, audit, reports, and seed code still import other `business.*` types. The issue stays open.
