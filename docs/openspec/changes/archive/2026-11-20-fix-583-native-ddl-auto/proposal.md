# Native helper uses ddl-auto none

## Objetivo

`workspace/stack/native.sh` still starts the backend with `--spring.jpa.hibernate.ddl-auto=update`, so a missing Flyway migration can pass on the local native stack. The packaged application already pins `none`.

## What Changes

- The native helper passes `ddl-auto=none`.
- A guard test rejects `ddl-auto=update` in that script.
- Spring profiles and the default CI schema check stay out. The issue stays open.

## Reglas de negocio

| Rule | Source | New / Changed / Made explicit |
|------|--------|-------------------------------|
| Flyway is the only schema writer when the backend starts | ADR-004, #583 | Made explicit |
