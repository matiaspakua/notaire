## Objetivo

ProcedureController create/update map SaveResult.ServerError to an empty 500 body.

## What Changes

Throw IllegalStateException on ServerError (and impossible Updated/Created arms) so GlobalExceptionHandler returns ErrorResponse. Add ProcedureControllerServerErrorResponseTest.
