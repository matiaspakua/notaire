## Objetivo

Epic #2238 phases B-D have no UI host, no Project/Run entities, a thin workflow body, no packaging and one adopter. The design record lives only in an issue body; agents need a permanent, linkable contract.

## What Changes

Add FACTORY-PRODUCT-ANALYSIS.md (verdict, findings F1-F12, reuse plan, SDLC improvements) and FACTORY-UI-SPEC.md (architecture, contract additions, entity model v2, UI spec, tests, slices, coordination, open Owner decisions). Link both from FACTORY-ROADMAP.md, the kit README and the 300-development index. Docs only; no kit code.
