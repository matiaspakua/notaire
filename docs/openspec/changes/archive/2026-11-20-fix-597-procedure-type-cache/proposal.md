# Cache the procedure-type catalog list

| Gate 1 status | passed |

## Objetivo

Every procedure-type list read hits the database. The catalog is read on nearly every page and changes only when an administrator edits it. This is the last catalog named in #597.

## What Changes

- `findAll` on the procedure-type ops port is cached for 60 seconds.
- Create, update, delete, and workflow assignment drop that cache.
- Name search and get-by-id stay uncached. Merging this change completes the catalogs named in #597.

## Reglas de negocio
