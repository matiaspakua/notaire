## Objetivo

ADR-030 and the Owner checklist on #1693 require an ArchUnit rule that use-case packages (`application.usecase.(*)`) do not form dependency cycles. Cycle reports are not stable class-to-class pairs, so they need their own shrink-only baseline (separate from R1–R6 in `hexagon-baseline.txt`). Without this guard, strangler slices can introduce silent cross-context cycles.

## What Changes

- Add an ArchUnit test that partitions `application.usecase.<slice>` packages and detects dependency cycles between slices.
- Store today's cycles (if any) in a dedicated shrink-only baseline file; fail on new cycles and on stale baseline entries.
- Document the rule and shrink command next to the existing hexagon guard.
- No production refactor, no REST/OpenAPI/CHANGELOG changes.
