## Objetivo

LikeC4 relationship ids hash the source location, so the committed architecture-model.json differed between worktrees and the drift check failed on any other checkout (found by the PR preflight of #2497).

## What Changes

Relationship findings get the id `source -> target: title`; a docs test pins it; the data is regenerated.

## Reglas de negocio

| Rule | Source | New / Changed / Made explicit |
|------|--------|-------------------------------|
| Generated data does not depend on the checkout | Issue #2483 (bug found after merge) | New |
