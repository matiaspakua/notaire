## Objetivo

`WorkflowNodeController` is still repo-only (~6 R1 edges — largest among the workflow trio). Migrate behind domain-typed ports without changing the REST contract.

## What Changes

- Characterization tests stay green.
- Domain WorkflowNode + inbound ports + use cases (delete blocked when transitions exist).
- WorkflowNodeCatalogPort; reuse WorkflowDefinitionCatalogPort and ManagementStatusCatalogPort for lookups.
- Controller ports-only; no controller @Transactional; ArchUnit R1 shrink.
