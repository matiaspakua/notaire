## Objetivo

Issue #1637 (SR-11, IDOR) requires an ADR that defines record ownership before any code. Authorization is role-based only, so any authenticated user can reach any record by id. The ownership data model is not decided: three tables carry an owning notary, the rest reach one only through foreign-key chains, and whether a deployment shares files across an office or isolates notaries is a product decision.

## What Changes

- New ADR-029 (Proposed): measured facts, three options, a recommended assigned-notary scope behind a deployment switch, tests-first plan and the one question the Owner must answer.
- ADR index row.
- No code and no behaviour change; #1637 stays open for the implementation once the Owner decides.
