## Objetivo

Migration README, database-migrations rule, and application.properties still describe V1–V2 and V1→V11+ while the schema is far past that; agents read the rule on every DB change.

## What Changes

Rewrite migration README conventions without a hand-kept V1/V2 table (point to Pages /docs/database/); explain R-script rollbacks; stop naming a version range in the rule and application.properties comment. Guard with a docs test that fails on V1→V11+ in those paths.

## Reglas de negocio

| Rule | Source | New / Changed / Made explicit |
|------|--------|-------------------------------|
| Flyway docs must not hard-code a closed version range (V1→V11+) or a hand-kept early migration table as current state. | Issue #1980; CU76 | New |
