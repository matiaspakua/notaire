## Objetivo

The public site explained what Notaire is and how agents are gated, but it had no illustrated explanation of how one request moves through the system, how development, QA, security and operations run as one loop over the environments, or what the AI SDLC is, why it exists and how it works. Terms were undefined, the reading path jumped between the product and the lifecycle, and some story components carried wrong or hand-typed claims (microservices, 786 commits, 200+ E2E tests).

## What Changes

- Three step-through isometric machines built with the anatomy kit: the notary's counter (`/product/anatomy/`), the release line (`/docs/engineering/`) and the lock chamber (`/ai-sdlc/anatomy/`).
- A glossary page, registry entries, search keywords, links from the landing page, the product overview, the docs overview and the AI Factory overview, and two steps in the reading path.
- A figure test that checks stations, moving parts and the repository paths each step cites; site-map and smoke tests updated.
- Content fixes in the story components and a contrast fix for the figure plates; a real README for the site.
