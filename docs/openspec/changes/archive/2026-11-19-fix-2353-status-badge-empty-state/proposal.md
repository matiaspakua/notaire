# e2e: status-badge check counts data rows, not the empty-state placeholder

> Governed by [CONSTITUTION.md](../../../../CONSTITUTION.md). This proposal documents
> **only this change**; permanent documentation remains the single source of truth.

| Field | Value |

| Gate 1 status | passed |

## Objetivo

TS-0124 counts the placeholder row of an empty list as data and fails on a correct page; the failing set changed between runs with the data the earlier tests left.

## What Changes

Count data rows only in the status-badge E2E helper; skip an empty list.

## Reglas de negocio

| Rule | Source | New / Changed / Made explicit |
|------|--------|-------------------------------|
| A check of data rows must not count the placeholder row of an empty list | #2353 | New |

## Capabilities

### New Capabilities
