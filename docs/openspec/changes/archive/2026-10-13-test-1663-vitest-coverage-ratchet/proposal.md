## Objetivo

The enforced frontend floors (14/9/10/14) date from 2026-10-03 when coverage was about 15%. A fresh `npx vitest run --coverage` measures 52.07/48.85/46.22/52.39, so the gate would let coverage fall about 38 points unnoticed. The raise-only policy says floors follow measured coverage.

## What Changes

- `frontend/vitest.config.ts` thresholds become 50/46/44/50 (at least 2 points below the measurement).
- The guard test documents the same floors; `code-quality.md` records the measurement.

## Reglas de negocio

|------|--------|-------------------------------|
