## Objetivo

Backend containers default to UTC. AuditRecordService interprets from/to with ZoneId.systemDefault(). Playwright fills those dates from the host calendar. After local midnight while UTC is still the previous day, TS-0016 CU23-GW01 sees an empty Auditoría table and preflight.sh --full fails. Product CI no longer runs that suite on PRs (#2001).

## What Changes

Pass TZ into compose services from ${TZ:-UTC}; when start.sh finds TZ unset, derive the host IANA zone from /etc/localtime (macOS/Linux) and export it before compose up.
