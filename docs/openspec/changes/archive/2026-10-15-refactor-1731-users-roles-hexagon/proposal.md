## Objetivo

`UserController` and `RoleController` are still repo-only (~4 R1 edges each). Migrate behind domain-typed ports without changing the REST/auth contract. Fence module-grant enforcement for sibling #1683.

## What Changes

- Characterization tests stay green (CRUD + login hash/MD5 upgrade + role assign).
- Domain User/Role + inbound ports + use cases (transactions in use cases).
- UserCatalogPort / RoleCatalogPort; PasswordHasherPort for encode/match.
- Controllers ports-only; no controller @Transactional; ArchUnit R1 shrink.
- Do not enforce role_modules (owned by #1683); only persist/read modules as today.
- CHANGELOG Unreleased under Changed.
