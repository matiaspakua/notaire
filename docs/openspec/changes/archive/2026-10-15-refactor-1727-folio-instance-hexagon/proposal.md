## Objetivo

`FolioController` is still repo-only. Folio types are already a clean hexagon (#1703). Migrate the folio instance aggregate behind domain-typed ports without changing the REST contract.

## What Changes

- Characterization tests stay green.
- Domain Folio + inbound ports + use cases (Utilizado lock, deed link).
- FolioCatalogPort + person/deed lookup ports; reuse FolioTypeCatalogPort.
- Persistence adapter; keep FolioRepositoryPort for AuxiliaryProtocol.
- Controller ports-only; ArchUnit R1 shrink.
- Omit CHANGELOG while #1718 holds Unreleased.
