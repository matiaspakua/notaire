# Stop hook: no agent stops with Issue-branch commits only on its disk

## Objetivo

Continuous publication (#1681) is mandatory but only reminded at session start; finished work has sat invisible on a local branch while its Issue blocked a lane (#1647). The audit's E4 asked for a Stop hook; this one checks one cheap, unambiguous fact.

## What Changes

- `.claude/hooks/stop-unpublished-work.sh`: on an Issue branch (`<type>/<n>_…`) whose commits are on no remote, block the stop once (exit 2) and name `publish-progress.sh <n>`.
- The retry (`stop_hook_active`) always passes; `main`, non-Issue branches and bad payloads never block.
- Registered in `.claude/settings.json`; documented in `.claude/rules/hooks.md`.
