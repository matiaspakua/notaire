## Objetivo

ManagementController create/update map SaveResult.ServerError to an empty 500 body, bypassing the standard ErrorResponse contract GlobalExceptionHandler and ErrorResponses use elsewhere.

## What Changes

Map SaveResult.ServerError on create/update to throw IllegalStateException so GlobalExceptionHandler returns the standard ErrorResponse JSON. Add ManagementControllerServerErrorResponseTest.
