## Objetivo

`ManagementController` is the largest remaining mixed-controller ArchUnit R1 hotspot (~17 edges): eight Spring Data repositories plus `business.*` entity imports, while also calling application services. `TransitionManagementWebMapper` adds three more R1 edges.

## What Changes

- Add ManageManagementsUseCase + QueryManagementsUseCase (and implementations) owning CRUD/complete-case/history/current-status paths that currently hit repositories from the controller.
- Move `@Transactional` and entity/repository access out of the web adapter; reuse existing management use cases (transition, archive, financial, document reentry, etc.).
- Make TransitionManagementWebMapper ports-only (query port / DTO, no DeedManagementRepository).
- Controller ports-only; shrink ArchUnit R1 for ManagementController + TransitionManagementWebMapper.
- Characterization/unit/integration tests stay green.
- Omit CHANGELOG Unreleased while Release Please #1766 holds it.
