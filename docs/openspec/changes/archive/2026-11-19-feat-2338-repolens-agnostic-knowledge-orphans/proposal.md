## Objetivo

repolens parses 26 extensions as code although the installed tree-sitter pack has 371 grammars (71 with tags queries); paths are linked only with a slash and an extension; identifiers only from Markdown code spans; and 215 Notaire files outside archives relate to nothing without anyone being told.

## What Changes

Detect every language through the pack; extract definitions and references through tags queries for languages without a hand-written spec; link files, directories and symbols named in any text with proximity-based resolution; report orphan files and symbols on the CLI, HTTP API, MCP and UI, and after each index run.
