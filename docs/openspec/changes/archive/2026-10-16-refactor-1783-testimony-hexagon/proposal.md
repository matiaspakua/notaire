## Objetivo

`TestimonyController` is a mid-size mixed ArchUnit R1 hotspot (~5 baseline edges): four Spring Data repositories plus `business.Testimony` with `@Transactional` on the web adapter.

## What Changes

- Add ManageTestimoniesUseCase + QueryTestimoniesUseCase and TestimonyOpsPort/adapter owning CRUD, delete-in-use checks, generate, and verify.
- Move `@Transactional` and entity/repository access out of the web adapter; reuse TestimonyGenerationVerificationService inside the adapter.
- Controller ports-only; shrink ArchUnit R1 for TestimonyController (five baseline edges).
- Characterization/unit/integration tests stay green.
- Omit CHANGELOG Unreleased while Release Please #1766 holds it.
