# Pages metrics stay valid JSON when the GitHub API fails

> Governed by [CONSTITUTION.md](../../../../CONSTITUTION.md). This proposal documents
> **only this change**; permanent documentation remains the single source of truth.

| Field | Value |
|-------|-------|
| GitHub Issue | #2507 |
| Use Case | CU76 — Quality Assurance and Testing Infrastructure |
| Branch | `fix/2507_metrics_gh_error` |
| Gate 1 status | passed |

## Objetivo

On a gh api error the error JSON went to stdout and `|| echo 0` appended a 0, so metrics.json became invalid. Parallel self-tests (#2502) hit the search rate limit and exposed it; a deploy could publish it.

## What Changes

Accept only a numeric answer; otherwise use the live pullRequests value or 0. Tests put a stub gh on PATH.

## Reglas de negocio

| Rule | Source | New / Changed / Made explicit |
|------|--------|-------------------------------|
| metrics.json is always valid JSON | Issue #2507 | New |
