## Objetivo

The page smoke test renders each list with an empty API, so the row, column and action branches stay uncovered. Rendering the same pages with one populated row per request raised measured coverage from 61.34/54.39/51.51/62.34 to 64.25/57.62/59.06/65.24.

## What Changes

- `dashboard-pages-render.test.tsx` renders every page a second time with a populated row and asserts no application error.
- Vitest floors rise from 59/52/49/60 to 62/55/57/63 (statements/branches/functions/lines) with the guard test and `code-quality.md` in step.
