## Objetivo

After #1671 the workflow list page (45% lines) and the protocol page (42%) are two of the largest gaps and carry rules only Playwright protects. Behaviour tests for both raised measured coverage from 72.81/64.90/68.77/73.99 to 74.23/65.96/69.64/75.51 and failed when the activation validation or the report URL and filters were broken.

## What Changes

- `workflows-admin-page.test.tsx` (9 tests): list, search, editor link, delete and its failure, name guard, create inactive, refusal of a new active workflow, activation only after backend validation, localized problem list for an invalid workflow.
- `protocol-page.test.tsx` (5 tests): folio list, the URL, filename and offered filters of the index book, monthly statement and tax statement, failed download keeps the dialog.
- Vitest floors rise from 70/63/66/71 to 72/63/67/73 with the guard test, `code-quality.md` and the testing inventory in step.
