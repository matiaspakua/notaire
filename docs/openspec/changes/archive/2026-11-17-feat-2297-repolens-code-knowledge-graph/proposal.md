## Objetivo

Agents working on this repository spend most of their steps on grep-driven discovery. A pre-built graph of files, symbols, tests, routes, tables and git co-change answers 'which files implement this, who calls it, which tests cover it' in one call. The module is built from free, open-source components and runs locally; it is a candidate tool for the AI SDLC kit, not an application dependency.

## What Changes

- New module `framework/ai-sdlc/graph-db` (package `repolens`): scanner, extractors, linker, SQLite store, hybrid retrieval engine, CLI, HTTP API, MCP server and graph explorer.
- Its own SDLC: `verify.sh`, `MODULE.md`, `CHANGELOG.md`, a CI template and reproducible benchmarks (retrieval, agent, performance, scale).
- Registered in `workspace/modules.yaml`; one row in the AI SDLC framework document.
