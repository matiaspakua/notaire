## Objetivo

Sonar java:S4973 (and SpotBugs RC_REF_COMPARISON) flagged boxed Integer optimistic-lock compares (`version != oldVersion`) across remaining *JpaController classes. They were deferred to hexagon (#1693); catalogs are far enough along that a hex-safe equals cleanup is the right fix without waiting for full jpa deletion (#576).

## What Changes

- Add OptimisticLockVersions.differ (Objects.equals) for boxed Integer versions.
- Replace all `version != oldVersion` in *JpaController with the helper.
- Fix PersonJpaController identification-type id boxed compare with Objects.equals.
- Pin with JpaOptimisticLockEqualsTest (value equality + source scan).
- Reclassify inventory S4973 rows from defer_hexagon to fix.
- Omit CHANGELOG Unreleased while Release Please #1766 holds it.
