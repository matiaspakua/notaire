## Objetivo

UserController create/update/delete catch Exception and return empty 500 or misleading empty 409 instead of GlobalExceptionHandler ErrorResponse.

## What Changes

Remove catch (Exception) from createUser/updateUser/deleteUser; keep UserNotFoundException and login anti-enumeration catch. Add UserControllerExceptionPropagationTest for unexpected create → 500 ErrorResponse.

## Reglas de negocio

| Rule | Source | New / Changed / Made explicit |
|------|--------|-------------------------------|
| Unexpected user API failures return the standard ErrorResponse via GlobalExceptionHandler. | Issue #579; CU76 | New |
