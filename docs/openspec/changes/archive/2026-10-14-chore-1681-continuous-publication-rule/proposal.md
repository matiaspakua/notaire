## Objetivo

An agent that stops suddenly loses everything that only exists locally, and the issue gives the next person or agent no hint of where the work stopped. The Owner requires GitHub to always hold the current state.

## What Changes

- Constitution sections 9 and 10, the Agent Card and the operational rules require: push the branch immediately when it is created; after each group of atomic commits (each SDLC stage) push and post a progress comment on the issue.
- workspace/sdlc/publish-progress.sh performs the push, verifies the remote head and posts the comment.
