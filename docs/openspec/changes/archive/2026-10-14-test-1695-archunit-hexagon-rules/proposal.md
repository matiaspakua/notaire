## Objetivo

The backend is only partly hexagonal (epic #1693): controllers reach repositories and JPA entities, the application layer imports entities and Spring Data, the domain package is tiny, and legacy jpa and service packages remain. Nothing stops these leaks from growing back, so the refactor needs a guard that can only move forward.

## What Changes

- ArchUnit 1.5.1 as a test dependency.
- HexagonArchitectureTest encodes six dependency rules over production classes.
- Each rule compares the dependencies found with a versioned baseline: a new violation fails the build and a baseline entry that no longer exists also fails, so the baseline can only shrink.
- A system property rewrites the baseline: init once, shrink to drop fixed entries.
- The application layer's only allowed framework annotations are Service and Transactional (Owner decision on #1693).
