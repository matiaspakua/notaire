## Objetivo

The managements page had 57.54% branch coverage (76 uncovered branches, the largest gap in the frontend). Its row actions were tested but not the create and edit form, the substitution redirect notice, the workflow transition dialog or the client filter. Thirteen behaviour tests raise it to 78.77% and fail when the property default, the redirect note rule, the status lock, the destination filter or the client filter is broken.

## What Changes

- `managements-page-form.test.tsx` (13): create values and failure, edit prefill and PUT body, save gating, redirect notices, transition destinations, refusal and cancel, client filter. The pickers and the select are small test doubles because Radix Select inside a Dialog loops the focus scope in jsdom.
