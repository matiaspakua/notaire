## Objetivo

Agents work from issue text, yet nothing checks that text. #2240 shipped with a `[#TBD-link-in-plan]` dependency and no labels; the phase issues have no test plan or size estimate. Each agent session then re-derives scope.

## What Changes

- New `aisdlc intake check <issue> [--json] [--file F]`: a pure `lint()` over the issue JSON (title, body, labels) with checks for required sections, an acceptance checkbox, placeholders, resolvable `#N` links and label prefixes; results are `pass | fail | no-evaluable`.
- Profile: `[tracker] fetch` (command printing the issue JSON) and an `[intake]` table (sections, label prefixes, placeholder words, link limit).
- Notaire profile enables it in advisory mode (not wired into a required gate).

## Reglas de negocio
