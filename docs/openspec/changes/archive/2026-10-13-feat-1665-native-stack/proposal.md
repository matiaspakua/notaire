## Objetivo

Claude Code cloud sessions have no Docker daemon, so Playwright, Bruno, pg-integration and database checks were reported as CI-only. Running PostgreSQL 16, the backend jar and Next.js natively on 2026-10-13 passed the suites and caught a PostgreSQL-only regression (#1635 read audit in a read-only transaction) that H2 and unit tests missed. The setup took about 15 manual steps.

## What Changes

- New `workspace/stack/native.sh` with `up`, `down`, `status`, `env`: PostgreSQL 16 in its own data dir with role and database `notaire`, the backend jar and the Next.js server with the same flags and secrets as `playwright-e2e.yml`, and the Playwright browser path shims.
- Idempotent; `down` stops only what `up` started.
- Test pins flags and secrets to the workflow and checks syntax and usage.
- Docs replace "Docker-only suites are CI-only" with the native path.
