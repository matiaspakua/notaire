## Why

## Objetivo

Adopters still copy or vendor framework/ai-sdlc manually. There is no single reversible lifecycle command for install, update, and uninstall that keeps the kit independent of product trees.

## What Changes

Add aisdlc install|update|uninstall: copy kit + scaffold profile; idempotent update; uninstall kit-managed paths only with optional --purge for scaffold/evidence; refuse frontend, backend-api, and product OpenAPI destinations.
