## Objetivo

Claude Code's PR-watching rules consult `.claude/skills/steward/SKILL.md` for repo-specific conventions. It does not exist, so agents re-derive Notaire's rules (heavy-CI false green, merge-not-rebase, archive-in-PR, strict required checks, who merges, sandbox-only failures) on every PR.

## What Changes

- New `.claude/skills/steward/SKILL.md` condensing the existing sources into one on-demand playbook (not always-loaded).
- Guard test: frontmatter present and every cited repo path exists.
- Listed in `.claude/skills/README.md`.
