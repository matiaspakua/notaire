# Revoked-token entity leaves the shared business package

> Governed by [CONSTITUTION.md](../../../../CONSTITUTION.md). This proposal documents

## Objetivo

`RevokedToken` is a logout row used only by the revocation service and its repository. It should not sit in the shared `business` package that config imports.

## What Changes

- The entity and repository move to `adapter.out.persistence.security`. The table name stays `revoked_tokens`.
- `TokenRevocationService` and its unit test import the new package.
- Role, user, audit, reports, and seed code still import other `business.*` types. The issue stays open.
