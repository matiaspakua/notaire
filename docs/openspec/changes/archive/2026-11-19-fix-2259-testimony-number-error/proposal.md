## Objetivo

The testimony register dialog already ties a bad number to the field. The edit dialog still rejected a blank or non-integer number with a toast only.

## What Changes

- The edit number field uses `FormField error` when save is pressed with a number that is not a positive integer.
- Typing a valid number, or closing the dialog, clears that error.
- No toast is shown for that check, and no request is sent.

## Reglas de negocio

| Rule | Source | New / Changed / Made explicit |
|------|--------|-------------------------------|
| A required-field error is a FormField error tied to its control, not a toast alone | FORMS-AUDIT-PLAN checklist (Errors) | New |
