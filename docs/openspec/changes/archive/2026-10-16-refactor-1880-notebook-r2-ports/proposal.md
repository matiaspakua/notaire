## Objetivo

ArchUnit R2 still flags the notebook application slice (~10 edges): entity-speaking NotebookRepositoryPort / DeedOperationPort / NotebookFolioOperationPort and entity-bound helpers NotebookService / AuxiliaryProtocolService.

## What Changes

Move entity-bound notebook helpers to adapter.out.persistence.notebook; delete entity-speaking notebook ports (helpers use Spring Data locally); keep view-safe NotebookOpsPort / AuxiliaryProtocolOpsPort; shrink hexagon-baseline (~10 R2 edges).
