## Objetivo

The RepoLens showcase shipped in #2316 is accurate but visually flat: numbered card grids, static charts without tooltips, and no animated explanation of how ranking works. Readers of a portfolio factory page need clearer hierarchy and purposeful motion without new metric claims.

## What Changes

- Critique then polish `/ai-sdlc/repolens/` (hero, sections, charts, factory-loop table).
- Add a stepped pipeline diagram for how RepoLens ranks code; chart entry motion + tooltips; scroll reveals.
- Honor prefers-reduced-motion; keep dark mode, ES/EN, and bench JSON as the only number source.
- Assess RepoLens HTTP explorer; leave it alone unless a tiny high-value fix is obvious.
