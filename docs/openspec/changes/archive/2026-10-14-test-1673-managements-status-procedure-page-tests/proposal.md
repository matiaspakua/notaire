## Objetivo

After #1672 the managements list (52% lines), the management status catalog (54%) and the procedure type catalog (56%) carry rules only Playwright protects. Behaviour tests for them raised measured coverage from 74.23/65.96/69.64/75.51 to 76.00/67.29/70.92/77.37 and failed when the archive confirmation flag, the hold-reason guard, the active-folder rule, the version resend or the in-use guards were broken.

## What Changes

- `managements-page-actions.test.tsx` (10 tests): archived-row guards, delete, history, archive without debt, debt warning, 409 conflict then confirmation flag, other archive failure, only the active folder can be held, hold needs a reason, hold with reason.
- `management-statuses-page.test.tsx` (6 tests) and `procedures-admin-page.test.tsx` (6 tests): name guard, create, edit (statuses resend the version), delete after confirmation, in-use warning, server search.
- Vitest floors rise from 72/63/67/73 to 74/65/68/75 with the guard test, `code-quality.md` and the testing inventory in step.
