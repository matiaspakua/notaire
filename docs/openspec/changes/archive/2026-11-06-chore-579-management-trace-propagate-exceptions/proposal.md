## Objetivo

ManagementController.getWorkflowTrace catches Exception and returns an empty 500 instead of GlobalExceptionHandler ErrorResponse.

## What Changes

Remove catch (Exception) from getWorkflowTrace; keep IllegalArgumentException → 400. Add ManagementControllerExceptionPropagationTest for unexpected buildTrace → 500 ErrorResponse.
