# Default COMPOSE_PROJECT_NAME for worktree observability

## Objetivo

Git worktrees publish <dirname>_notary-network instead of notaire_notary-network, so the observability stack cannot scrape or receive OTLP from the app.

## What Changes

- workspace/stack/start.sh defaults COMPOSE_PROJECT_NAME to notaire (still overridable for parallel stacks).
- Isolation test and deployment guide document the contract.

## Reglas de negocio

| Rule | Source | New / Changed / Made explicit |
|------|--------|-------------------------------|
| start.sh MUST default COMPOSE_PROJECT_NAME to notaire so the app publishes notaire_notary-network unless an operator overrides it | #1678 | New |
