## Objetivo

The Owner decided on #1637 that each notary runs an independent installation, with a customizable role template instead of per-record ownership. ADR-029 and the SAD still described the rejected assigned-notary design.

## What Changes

- ADR-029 is rewritten (Accepted) with the decision, the challenges found in the code and work items W1-W3 (#1682-#1684).
- SAD sections 7.5 and 8.1 and the SR-11 rows of the security docs state the tenancy model.
