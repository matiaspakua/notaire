## Objetivo

About 20 dashboard pages have 0% unit coverage, so a page that crashes on render is only caught by the slow Playwright suite. After #1663 the floor is 50/46/44/50 against 52/49/46/52 measured.

## What Changes

- One Vitest file renders every route-param-free dashboard `page.tsx` against an empty API and asserts it renders and settles without an application error.
- Measured coverage rises from 52.07% to 61.34% statements; the raise-only floors become 59/52/49/60 in `vitest.config.ts` and the guard test; `code-quality.md` records the measurement.
