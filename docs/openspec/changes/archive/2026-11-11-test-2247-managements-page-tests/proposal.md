## Objetivo

The managements page kept 45 uncovered branches (77%) after the earlier action and form tests. Twenty more behaviour tests raise it to 91% and fail when the required-field gate, the archive-conflict handling, the hold-reason rule or the transition fallback is broken.

## What Changes

Nine tests in `managements-page-form.test.tsx` (required fields, default heading, sparse rows and cases, edit without property and notes, failed edit, list and client-list load errors with retry, transition fallback) and eleven in `managements-page-actions.test.tsx` (archive conflict fallback and dismissal, server reason, missing balance, delete and history and folders dialogs closing, hold form cancel and failure, folder without number).
