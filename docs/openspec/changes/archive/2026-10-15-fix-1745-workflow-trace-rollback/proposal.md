## Objetivo

Mac verify-signals E2E (#1740) logged ~1856 UnexpectedRollbackException ERRORs on GET /api/v1/managements/{id}/workflow-trace. Controller @Transactional(readOnly=true) plus catch of IllegalArgumentException marks the TX rollback-only then commits → ERROR spam while clients still get 400.

## What Changes

- Remove @Transactional from ManagementController.getWorkflowTrace (TX stays on WorkflowTraceService).
- Guard: method has no Transactional annotation; 400 path does not emit UnexpectedRollbackException.
- CHANGELOG Bug Fixes entry.

## Reglas de negocio

| Rule | Source | New / Changed / Made explicit |
|------|--------|-------------------------------|
| GET workflow-trace MUST NOT emit UnexpectedRollbackException for expected 400 outcomes | CU77, #1745 | New |
