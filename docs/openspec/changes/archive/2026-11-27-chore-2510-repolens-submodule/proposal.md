# Consume RepoLens as an independent git submodule

> Governed by [CONSTITUTION.md](../../../../CONSTITUTION.md). This proposal documents
> **only this change**; permanent documentation remains the single source of truth.

| Field | Value |
|-------|-------|

## Objetivo

RepoLens is a portable product (ADR-006). Keeping a vendored copy inside Notaire duplicated history and blocked an independent release home. The code now lives at draclab/repolens (MIT, private) with full filtered history; Notaire must consume it without changing module paths or harness wiring.

## What Changes

- Replace the vendored `framework/repolens/` tree with a git submodule of `https://github.com/draclab/repolens.git`.
- Keep `workspace/modules.yaml` path and `verify` command unchanged.
- Document clone/`submodule update --init` and CI checkout with a read-only deploy key for the private product repo.
- Preserve harness wiring tests and the RepoLens module gate.

## Reglas de negocio
