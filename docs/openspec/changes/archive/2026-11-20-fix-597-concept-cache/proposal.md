# Cache the concept catalog list

> Governed by [CONSTITUTION.md](../../../../CONSTITUTION.md). This proposal documents
> **only this change**.

| Field | Value |
|-------|-------|
| GitHub Issue | #597 |
| Use Case | CU74 — Performance and Caching Strategy |
| Branch | `cursor/597-concept-cache-47dc` |
| Gate 1 status | passed |

## Objetivo

Every concept list read hits the database. The catalog is read on nearly every page and changes only when an administrator edits it.

## What Changes

- `findAll` on the concept ops port is cached for 60 seconds.
- Create, update, and delete drop that cache.
- Name search and get-by-id stay uncached. Procedure types, the last catalog named in #597, stay unchanged. The issue stays open.

## Reglas de negocio
