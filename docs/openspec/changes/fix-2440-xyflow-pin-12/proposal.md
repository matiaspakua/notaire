# Pin @xyflow/react 12 until the workflow editor is migrated to 13

> Governed by [CONSTITUTION.md](../../../../CONSTITUTION.md). This proposal documents
> **only this change**; permanent documentation remains the single source of truth.

## Objetivo

Dependabot's major bump to @xyflow/react 13 removed applyNodeChanges; the workflow editor no longer builds and every frontend or Pages gate fails on main.

## What Changes

Pin @xyflow/react ^12.12.1, guard the used API with a unit test, ignore xyflow majors in Dependabot, file the v13 migration.

## Reglas de negocio

| Rule | Source | New / Changed / Made explicit |
|------|--------|-------------------------------|
| Majors that break the build are pinned and migrated in their own change; main must build. | .github/dependabot.yml (#1643, #1883 precedent) | New |
