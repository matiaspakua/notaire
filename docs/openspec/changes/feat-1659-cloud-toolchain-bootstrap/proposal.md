## Objetivo

Cursor Cloud has `.cursor/install.sh`; Claude Code cloud sessions have nothing. A fresh session ships JDK 21, no `openspec`, no `kustomize`, no `trivy` and a POSIX locale, so an agent cannot run Gate 1 (`openspec`), backend build (JDK 26), Spotless (non-ASCII file names) or the SCA gate without hand-installing tools. Autonomy needs the loop to start green.

## What Changes

- New `SessionStart` hook `.claude/hooks/session-start-toolchain.sh`: in cloud sessions only, idempotently installs Temurin 26, the pinned `openspec`, `kustomize` and the pinned Trivy into a user cache, and exports `JAVA_HOME`, `PATH`, `LC_ALL`, `KUSTOMIZE` and `OPENSPEC_TELEMETRY` through `CLAUDE_ENV_FILE`.
- Never blocks session start; one warning line per tool that could not be installed.
- Guard test pins the versions to the files that already own them.
