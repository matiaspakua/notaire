## Objetivo

Trivy 0.75 reports 3 CRITICAL findings in the embedded Tomcat 11.0.24 (CVE-2026-65182 security-constraint bypass, CVE-2026-65905 authentication bypass, CVE-2026-68525 unauthorized resource access via FORM auth) and 10 HIGH findings in Jackson 2.21.5 and 3.1.5. Spring Boot 4.1.1, the latest release, still manages these versions. The backend must run on patched versions now, without waiting for a Boot release.

## What Changes

- Root `pom.xml` overrides Spring Boot's managed version properties: `tomcat.version` 11.0.26, `jackson-2-bom.version` 2.21.7, `jackson-bom.version` 3.1.7. Each stays on the line Boot manages, with a comment saying when to remove it.
- `PatchedDependencyFloorTest` reads the version each library reports about itself and fails below the fixed release on its line. It also checks that the CVE-2015-7501 commons-collections gadget stays off the classpath.
- commons-collections 2.1, commons-beanutils, itext and bcprov from the original finding already left with JasperReports in #1328.
