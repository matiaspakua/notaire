## Objetivo

`/actuator/prometheus` is protected by HTTP Basic. `ProductionCredentialsGuard` only rejects the literal value `admin`, so production can still start with `password`, `changeme`, an empty value or a 3-character password (OWASP A05, ADR-019). `.env.example` ships `ACTUATOR_PASSWORD=admin`, which invites copy-paste into production.

## What Changes

- Under `app.environment=production` the backend refuses to start when the actuator password is empty, shorter than 16 characters or on a deny-list, or when the actuator user is empty or on the deny-list.
- `.env.example` uses `change-me-…` placeholders plus a generation hint; dev compose keeps its dev-only default with a comment.
- ADR-019 and `OWASP-TOP10.md` (A05 row) updated.

## Reglas de negocio

| Rule | Source | New / Changed / Made explicit |
|------|--------|-------------------------------|
| A production actuator password has at least 16 characters and is not on the deny-list; the actuator user is not empty or on the deny-list | #1639, ADR-019, OWASP A05 | New |

- Rotating secrets in shared environments.
