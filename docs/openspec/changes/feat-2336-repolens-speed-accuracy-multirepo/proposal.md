## Objetivo

The factory loop measured repolens slower than rg on every CLI call (0.7-4.5 s vs 0.002-0.19 s), wrong or missing callers on ambiguous method names, a 21-minute embedding on each new cloud VM, no way to ask across repositories, and 11% more input tokens per Sonnet session.

## What Changes

- Java receiver types and dispatch-aware `impact`, scored against a javac call graph.
- A resident per-worktree service behind the CLI.
- `repolens cache export/import` and `[embed] skip`.
- A machine registry of indexed repositories and federated search (CLI and MCP).
- Smaller MCP tool schemas and instructions.
