## Objetivo

Property already has a use case, a service, an outbound port and an adapter, but they are pass-through wrappers over the JPA entity and nothing calls the use case: PropertyController injects PropertyRepository directly. The existing structure looks like a hexagon without being one.

## What Changes

- A pure domain Property with creation and change rules, and a not-found domain exception.
- New inbound ports (query, manage) and an outbound catalog port in domain terms, with use cases holding the behaviour.
- A persistence adapter mapping the legacy entity; an in-memory adapter for the use-case tests.
- PropertyController calls the inbound ports only; an advice maps the not-found exception to the unchanged empty 404.
- The dead PropertyUseCase and PropertyService are deleted; the entity-returning PropertyRepositoryPort stays for its current callers (procedures, reports, registration drafts) and is recorded as debt.
- The SAD current-state table is corrected to interface counts.
