## Objetivo

Grafana Postgres business panels and quality views stay empty because postgres-exporter never loads its queries file, several PromQL expressions do not match exported series, operators cannot see packaged SEMVER next to status tiles, and SonarQube has no provisioned Grafana overview. The deprecated grafana-piechart-panel install also adds Grafana startup noise.

## What Changes

- Mount and set PG_EXPORTER_EXTEND_QUERY_PATH so postgres_exporter.yml is loaded; rewrite the file to extend-query metric-key format.
- Fix notaire-postgres PromQL (cache hit ratio, connections by state).
- Tag Micrometer metrics with version=${app.version}; show Product version on notaire-status and notaire-backend.
- Add provisioned notaire-quality dashboard (Sonar probes + load guide) and Homer links.
- Stop installing grafana-piechart-panel (native piechart already used).
- Guard tests in infra/tests/test_obs_dashboard_wiring.py; document load/recreate steps.
