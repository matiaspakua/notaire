# ui-gestiones — delta

## Purpose

The managements list screen.

## MODIFIED Requirements

### Requirement: Managements list identifies each case

The managements list SHALL show each case's number, header, start date, procedure count (titled as such) and status.

#### Scenario: Row identifies the case

- **WHEN** a management is created with a header
- **THEN** its row shows number, header and start date under the right titles
