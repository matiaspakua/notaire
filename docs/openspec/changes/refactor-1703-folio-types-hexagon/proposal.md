## Objetivo

FolioTypeController injects two repositories, uses the legacy entity's DTO conversion, carries four transaction annotations and holds the rules: a type used by folios cannot be edited or deleted, an in-use query, search by name, and optimistic locking on the client-supplied version.

## What Changes

- A pure domain FolioType with creation and change rules and domain exceptions without HTTP status.
- Inbound ports (query, manage), outbound ports (catalog, usage) and use cases holding the rules.
- A persistence adapter mapping the legacy entity, which stays for FolioController, the folio adapter and the reports.
- The controller calls the inbound ports only and keeps its DTO and OpenAPI signatures; an advice maps the domain exceptions to the unchanged responses.
- The controller's baseline entries are removed.
