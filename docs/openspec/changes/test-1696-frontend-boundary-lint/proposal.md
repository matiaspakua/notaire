## Objetivo

The frontend has no hexagon (epic #1693): 22 files under app, 43 hooks and 1 component import the API client directly, and nothing stops more. The boundaries of ADR-030 need to be executable from the first slice.

## What Changes

- ESLint no-restricted-imports and no-restricted-globals rules: app, components and hooks may not import lib/api-client or call fetch; core may not import React, Next, TanStack, lib, adapters or UI, nor use browser globals.
- Today's violations are recorded with ESLint's own suppression file, eslint-suppressions.json, which is the shrink-only baseline.
- A Vitest suite pins the rules with virtual files and checks the baseline file.
- npm run lint already runs in CI, so the gate needs no new job.
