### Categoría funcional

- `[BACKEND]` - API REST, servicios, persistencia
- `[FRONTEND]` - Swing forms, UI, client REST
- `[DB]` - Schema, migración, optimización
- `[DEVOPS]` - Docker, CI/CD, deployment
- `[TEST]` - Unit tests, integration tests, E2E
- `[DOC]` - Documentación técnica/usuario
- `[REFACTOR]` - Mejora de código sin cambio funcional
