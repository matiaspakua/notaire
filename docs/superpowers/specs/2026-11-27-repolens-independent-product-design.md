# RepoLens as an independent product

**Date:** 2026-11-27  
**Status:** Implemented (product pushed; Notaire on `chore/2510_repolens_submodule`)  
**Issue:** [#2510](https://github.com/matiaspakua/notaire/issues/2510)  
**Decisions owner:** Matias  
**Product:** https://github.com/draclab/repolens (private, MIT, history via `git subtree split`)  


## Goal

Make `framework/repolens/` a standalone git product at
[`https://github.com/draclab/repolens.git`](https://github.com/draclab/repolens.git),
and have Notaire consume it as a **git submodule** at the same path.

## Decisions (locked)

| Topic | Choice |
|---|---|
| Notaire relationship | Submodule at `framework/repolens` (same path) |
| History | Full filtered history via `git subtree split --prefix=framework/repolens` |
| License | MIT |
| Visibility | Private (unchanged) |
| Scope of this work | Export + product polish + Notaire submodule swap |
| Out of scope | Public release, PyPI publish, API/CLI changes, relocating Notaire-specific benches |

## Context

- RepoLens is already a portable Python package (`pyproject.toml`, `PORTABILITY.md`, ADR-006):
  the AI SDLC kit calls it as CLI / MCP / HTTP and must not import it.
- Target repo exists, is empty, private; caller has admin push.
- ~21 commits touch `framework/repolens/` in Notaire — manageable for subtree split.
- Approach chosen: **git subtree split** (no `git-filter-repo` required).

## Architecture

```text
notaire (adopter)
  framework/repolens/   ← git submodule → github.com/draclab/repolens (product)
  repolens.toml         ← adopter profile (stays in notaire)
  harness wiring        ← generated by `repolens setup` (stays in notaire)
```

### Product repo (`draclab/repolens`)

Contents = current `framework/repolens/` tree at repo root after split:

- Package `repolens/`, `tests/`, `bench/`, `bin/`, `ci/`, `pyproject.toml`, `README.md`,
  `CHANGELOG.md`, `PORTABILITY.md`, `MODULE.md`, `verify.sh`
- New: `LICENSE` (MIT)
- Adjust CI workflow paths from `framework/repolens/**` to repo root
- GitHub description set; default branch `main`

### Notaire integration

1. Remove tracked tree `framework/repolens/`.
2. `git submodule add https://github.com/draclab/repolens.git framework/repolens`.
3. Keep `workspace/modules.yaml` path/verify unchanged (path still `framework/repolens`).
4. Document `git submodule update --init --recursive` for clones/CI where missing.
5. Integration tests that assert files under `framework/repolens/` keep working once the
   submodule is initialized.

## Procedure

### A. Export

1. Fresh clone of Notaire at a known tip (prefer `origin/main`).
2. `git subtree split --prefix=framework/repolens -b repolens-export`.
3. Push `repolens-export` to `draclab/repolens` as `main`.
4. On product `main`: add MIT `LICENSE`; fix `ci/repolens.yml` paths for a root checkout;
   light MODULE/README wording so the product is not described as “only a Notaire module”.
5. Set GitHub repo description.

### B. Notaire submodule

1. Branch from updated `main` (CONSTITUTION: Issue + Use Case when required by process).
2. Replace directory with submodule; commit `.gitmodules`.
3. Ensure preflight / verify still call `bash framework/repolens/verify.sh`.
4. Smoke: launcher executable, `python3 -m pytest` in submodule, integration unittest that
   needs `MODULE.md` under the ref.

### C. Verification

| Where | Check |
|---|---|
| Product | `python3 -m pytest -q`; `python3 -m repolens --help`; optional `bash verify.sh` |
| Notaire | `git submodule update --init`; `bash framework/repolens/verify.sh`; `python3 -m unittest workspace.tests.test_repolens_integration` |

## Risks and mitigations

| Risk | Mitigation |
|---|---|
| Detached / dirty Notaire worktree | Export from a clean temporary clone |
| Private submodule breaks CI without credentials | Document token/SSH; submodule URL stays HTTPS to `draclab/repolens` |
| `subtree split` omits commits that only touched Notaire wrappers | Acceptable: product history is the prefix history |
| Double history if someone re-copies files | Submodule only; no vendored duplicate |

## Success criteria

- `draclab/repolens` has non-empty `main` with split history and MIT license.
- Notaire `framework/repolens` is a submodule pointing at that repo.
- Existing Notaire module path and verify command keep working after `submodule update --init`.
- No intentional change to RepoLens query/index behaviour.
