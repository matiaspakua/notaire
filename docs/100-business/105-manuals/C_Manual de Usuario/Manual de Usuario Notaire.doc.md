[XII.	Glosario	94](#glosario)

1. **Introducción**

El presente documento es una herramienta de consulta para el usuario del sistema *Notaire*, y tiene la finalidad de brindar al usuario la ayuda necesaria para lograr eficacia y rapidez en el uso del sistema.

Es un sistema que corre bajo un entorno visual de uso intuitivo para el usuario, e incorpora herramientas de última tecnología que facilitan el uso del mismo.

1. ***Objetivos***

El objetivo del presente manual, es asistir al usuario con el manejo de la aplicación, otorgándole los conocimientos básicos de cómo opera el sistema, y así mostrar el alcance del mismo.

2. ***A quién va dirigido el manual***

Este manual va dirigido a los usuarios finales, involucrados en la operación del sistema, los que deben tener conocimiento básico del uso del computador, para poder llevar a cabo el curso completo de la gestión de un trámite.

2. **Ingreso al sistema Notaire**

En este apartado, se detallará brevemente la forma en que el usuario debe acceder al sistema:

En el escritorio podrá observar el icono de acceso al sistema:

![][image2]

Hacer doble clic con el mouse sobre este icono. Luego observará la ventana “Login” del sistema, para poder ingresar al mismo. En esta ventana podrá observar que se solicita el nombre de Usuario y su respectiva contraseña, por lo que deberá indicar las mismas para poder ingresar.

Nota: Si no posee un Usuario para ingresar, solicite al Administrador del sistema a cargo, que le asigne uno.

![][image3]

Hacer clic sobre el botón “Aceptar”, para ingresar al sistema.

Si alguno de los datos ingresados no es válido, aparecerá una advertencia, en caso contrario, ingresará a la ventana principal del sistema.

4. **Clientes**

1. ***Introducción***

Esta sección provee las herramientas necesarias para la administración de las Personas y Clientes involucrados en una gestión.

En el sistema, se distinguen Persona y Cliente por el siguiente motivo:

* **Persona**: consiste en una persona que no ha realizado aún ninguna gestión, por lo que se saben sólo los datos básicos de la misma. A continuación se listan los datos requeridos:

  * Nombre (\*)

  * Apellido (\*)

  * Tipo de Identificación (\*)

  * Número de identificación (\*)

  * Número de Teléfono

  * Dirección de Correo Electrónico

* **Cliente**: consiste en una persona que ha realizado, por lo menos una vez, una gestión. Para poder ser dado de alta como Cliente, previamente debió haber sido dado de alta como Persona. Al considerarlo un Cliente, se saben además los siguientes datos de la misma:

  * Nacionalidad

  * Fecha de Nacimiento

  * Cuit/Cuil

  * Estado civil (si es casado/divorciado/viudo: Número de nupcias)

  * Sexo

  * Ocupación

  * Domicilio

(\*) Datos Obligatorios.

Para acceder a la sección de Clientes debe hacer clic en el botón de la barra de Herramientas “Clientes”:

![][image10]

10. **Ventanas de Búsqueda**

Las ventanas de búsqueda, son una herramienta que nos permite encontrar datos necesarios para la utilización de algunas funciones del sistema.

1. ***Buscar Persona/Cliente/Gestiones***

Al hacer clic sobre el botón “Buscar”, de alguna sección relacionada con clientes o personas, se abrirá la siguiente ventana:

![][image171]

Usted deberá ingresar los datos, según por qué criterio desee buscar a la Persona/Cliente, en este caso podrá realizar la búsqueda por:

* Nombre y/o Apellido: La búsqueda se realizará por aproximación, ya sea por nombre o apellido, o ambos.

* Tipo y número de Identificación: se buscará la combinación exacta de tipo de identificación y número.

Para realizar la búsqueda, hacer clic sobre el botón “Buscar”, generalmente se abrirá la siguiente ventana:

![][image172]

Hacer clic sobre la persona/cliente que desee, y se cargarán los datos del mismo, en la ventana correspondiente.

Hacer clic sobre el botón “Cerrar”, si desea cerrar la búsqueda.

2. ***Buscar Presupuesto***

Al hacer clic sobre el botón “Buscar”, de alguna sección relacionada con presupuestos se abrirá la siguiente ventana:

![][image173]

La búsqueda asociada a personas, es igual que [Buscar Persona/Cliente/Gestiones](#las-ventanas-de-búsqueda,-son-una-herramienta-que-nos-permite-encontrar-datos-necesarios-para-la-utilización-de-algunas-funciones-del-sistema.). Luego de seleccionar una persona, se abrirá una grilla con los presupuestos asociados a la misma, como la siguiente:

![][image174]

Hacer clic sobre el presupuesto que desee y se completarán los datos del mismo en la ventana que corresponda.

Para buscar un presupuesto en particular, podrá ingresar el número del mismo, y se completarán los datos del mismo en la ventana que corresponda.

Hacer clic sobre el botón “Cerrar”, si desea cerrar la búsqueda.

3. ***Buscar Escritura***

Al hacer clic sobre el botón “Busca”, de alguna sección relacionada con escrituras se abrirá la siguiente ventana:

![][image175]

Seleccione un número de Registro o ingrese el número de escritura a buscar.

Si selecciona un número de Registro, se abrirá la siguiente ventana:

![][image176]

Se muestra una lista de escrituras asociadas al Registro seleccionado.

Para ver el detalle de alguna escritura o para seleccionarla para ir al siguiente paso, según corresponda, hacer clic en la grilla, sobre la escritura que desea seleccionar.

12. **Glosario**

* ***Sistema:*** Un sistema de información (SI) es un conjunto de elementos orientados al tratamiento y administración de [datos](http://es.wikipedia.org/wiki/Dato) e [información](http://es.wikipedia.org/wiki/Informaci%C3%B3n), organizados y listos para su uso posterior, generados para cubrir una necesidad u objetivo.

* ***Botón***: 

  * [Control](http://es.wiktionary.org/wiki/control#Espa.C3.B1ol) que se [presiona](http://es.wiktionary.org/w/index.php?title=presionar&action=edit&redlink=1) para [activar](http://es.wiktionary.org/wiki/activar) o [regular](http://es.wiktionary.org/wiki/regular) la [función](http://es.wiktionary.org/wiki/funci%C3%B3n) de un [mecanismo](http://es.wiktionary.org/wiki/mecanismo). 

  * [Representación](http://es.wiktionary.org/wiki/representaci%C3%B3n#Espa.C3.B1ol) [gráfica](http://es.wiktionary.org/wiki/gr%C3%A1fico) de un botón, que cumple la función de este en una [interfaz](http://es.wiktionary.org/wiki/interfaz) informática.

* ***Clic***: [Clic](http://es.wikipedia.org/wiki/Clic_\(inform%C3%A1tica\)), la acción de presionar algún botón del [ratón](http://es.wikipedia.org/wiki/Rat%C3%B3n_\(inform%C3%A1tica\)) o mouse.

* ***Ventana***: En [informática](http://es.wikipedia.org/wiki/Inform%C3%A1tica), una ventana es un área visual, normalmente de forma rectangular, que contiene algún tipo de [interfaz de usuario](http://es.wikipedia.org/wiki/Interfaz_de_usuario), mostrando la salida y permitiendo la entrada de datos.
