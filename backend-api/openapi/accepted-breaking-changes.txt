# OpenAPI breaking changes the Owner has accepted (oasdiff err-ignore list).
#
# openapi-contract.yml and workspace/sdlc/preflight.sh pass this file to
# `oasdiff breaking --fail-on ERR --err-ignore`. A breaking change listed here
# does not fail the gate; any other one still does.
#
# The list is empty by default (issue #1315). Add an entry only when the break
# is intended and reviewed, in the pull request that introduces it:
# - copy the line oasdiff prints as "<METHOD> <path> <change text>";
# - put it under a comment that names the issue and why no working client
#   breaks;
# - record it in the CHANGELOG, comment on the issue, and get Owner approval
#   in review.
#
# Once that pull request is merged, the base spec already contains the break,
# so the entry accepts nothing and would hide a later break with the same text.
# workspace/sdlc/check-accepted-breaking-changes.py fails the next pull request
# until the entry and its comment are removed.
