# Report logo contract

Until the Owner approves a print-quality Notaire mark (SVG or transparent PNG ≥600 px wide),
the PDF adapter draws the text wordmark **Notaire**.

Do not package or upscale `docs/images/logoRojoLetraMediano.png` (100×100).
Do not load a logo from a request-selected filesystem path or remote URL.

When an approved asset is added, place it here as `notaire-wordmark.png` (or `.svg`)
and document the license next to it. Decorative marks use empty alt text; a
meaningful wordmark uses the accessible name "Notaire".
