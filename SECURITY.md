# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities in Notaire privately. This repository uses
GitHub private vulnerability reporting:

https://github.com/matiaspakua/notaire/security/advisories/new

Do not file a public issue for a security report.

## What to include

- The component you tested (backend API, frontend, or infrastructure)
- Steps to reproduce
- The impact you believe the issue has

Reports are acknowledged on that advisory thread. A fix is coordinated before
any public disclosure.
